目标与约束（从文档抽取）

编辑器结构固定：MediaPanel / PreviewPanel / PropertiesPanel / Timeline；状态以多 Store 切分（Editor/Timeline/Media/Playback/Project/Panel）。

视频处理主要在前端（FFmpeg.wasm + Web Workers），强调隐私与本地文件系统（IndexedDB/OPFS）。

总体架构（前端为主，后端可选）

A. 预览通路（实时）

WebCodecs（有则用）→ OffscreenCanvas 合成；无则 <video> + requestVideoFrameCallback 回退。

TimelineStore 按播放头计算“可见片段 + 转场权重”；MediaStore 统一从 Proxy 媒体读取（见下）。

文本/字幕：渲染在 Canvas 图层；编辑所见即所得。

B. 导出通路（离线）

前端 100% 离线导出（默认）：FFmpeg.wasm 放在 Worker，分段渲染 → 对齐编码参数 → concat，避免一次性吃爆内存。

后端导出（可选开关）：若启用 /api/export，把 IR + 媒体定位（或上传指针）发到服务端，用原生 FFmpeg（可 GPU/NVENC）出片；但默认关闭以符合隐私。

关键设计一：中间表示 IR（从 Store 编译）

把时间轴编译成稳定 IR，贯通“预览”和“导出”。

// types/ir.ts
export type Time = number; // ms
export interface IR {
  width: number; height: number; fps: number;
  video: Array<{
    id: string; src: string; in: Time; out: Time; start: Time; trackId: string;
    transform?: { x?:number; y?:number; scale?:number; rotate?:number };
  }>;
  audio: Array<{ id: string; src: string; in: Time; out: Time; start: Time; trackId: string; gain?: number }>;
  texts: Array<{ id:string; text:string; start:Time; end:Time; style:{
    x:number; y:number; fontFamily:string; fontSize:number; color:string; align?:'left'|'center'|'right'; shadow?:{x:number;y:number;blur:number;color:string}
  }}>;
  transitions: Array<{ id:string; between:[string,string]; kind:'cross'|'fade'|'wipe'; duration:Time }>;
}


编译口：TimelineStore.toIR() + MediaStore.resolve(src→OPFS/URL)；

IR 是唯一事实源：前端预览与导出都只依赖 IR，便于测试与重构。

类型与文档描述的 Store 切分保持一致，落地成本低。

关键设计二：Proxy 媒体与 OPFS

导入即排队（Worker + wasm）生成 Proxy（540p/720p、恒定 fps），存 OPFS；缩略图/波形也基于 Proxy。

预览用 Proxy；导出用源文件（或在“快速导出”时用 Proxy）。

统一的 MediaCache：LRU + 软上限（如 512MB），防止多段同时解码把内存打满。

这些都符合你文档里的“本地存储与性能优化”。

关键设计三：字幕策略（14 段）

编辑期：Canvas 文本图层；

导出期：TextClip → ASS（定位/描边/阴影/多行稳定），FFmpeg 以 subtitles=subs.ass:fontsdir=./fonts 硬烧，或把 .ass 软封装（播放器可切换）。

这样避免复杂的 drawtext 表达式，也便于风格统一。

生成器放 lib/subtitle/ass.ts；在 /api/export 模式也复用同一个文件。

关键设计四：分段渲染 + 无损拼接

为什么分段？ 22 段视频 + 过渡 + 文本在纯 wasm 上一次性跑，极易 OOM/超时。
做法：把时间轴按“过渡断点/剪切点”切成 N 段小 Composition（每段数十秒级），每段单独渲染为 同编码参数 的片段，然后 concat demuxer 无重编码拼接：

每段统一：-r ${fps} -pix_fmt yuv420p -c:v libx264 -preset veryfast -crf 20 -profile:v high -level 4.2 -c:a aac -b:a 160k

拼接：生成 inputs.txt → -f concat -safe 0 -i inputs.txt -c copy out.mp4

若某段存在“需要滤镜的转场/变换/字幕”，就在该段内部完成全部滤镜；段与段之间尽量 纯拼接（速度与稳定性最好）。

这一套在前端 wasm 也能跑通（时间换稳定），而在后端 FFmpeg 更快；可以作为“性能/隐私”拨盘。

关键设计五：转场/效果生成器

同类转场（如 crossfade）：段内 xfade/acrossfade；

复杂转场（wipe/slide）：优先用 xfade=transition=... 的内建类型；极复杂的（带蒙版）走 alpha 合成：
format=rgba, split[a][b]; [a]…; [b]…; [a][b]alphamerge

统一入口 lib/ffmpeg/graph.ts：把 IR → filter_complex 字符串；单元测试覆盖“22 段组合”。

关键设计六：进度与容错

wasm 端解析 stderr 的 frame/time/speed，映射到导出进度（段内 + 总体）。

失败自动从当前段重试，不必重头来。

临时文件都写 OPFS，最终产物导出 Blob/FileSystemHandle。

文档已有“进度回调、Worker 避免阻塞”的前提，这里正好对齐。

示例代码（硬字幕烧录）：

import { createFFmpeg, fetchFile } from "@ffmpeg/ffmpeg";

const ffmpeg = createFFmpeg({ log: true });

async function exportWithSubtitles(clips: Clip[], subsASS: string) {
  await ffmpeg.load();

  // 写入视频片段
  for (let i = 0; i < clips.length; i++) {
    ffmpeg.FS("writeFile", `clip${i}.mp4`, await fetchFile(clips[i].file));
  }

  // 写入字幕文件
  ffmpeg.FS("writeFile", "subs.ass", new TextEncoder().encode(subsASS));

  // 生成 concat 列表
  let list = clips.map((_,i)=>`file 'clip${i}.mp4'`).join("\n");
  ffmpeg.FS("writeFile", "inputs.txt", new TextEncoder().encode(list));

  // 执行合并 + 硬字幕烧录
  await ffmpeg.run(
    "-f", "concat", "-safe", "0", "-i", "inputs.txt",
    "-vf", "subtitles=subs.ass",
    "-c:v", "libx264", "-preset", "veryfast", "-crf", "23",
    "-c:a", "aac",
    "output.mp4"
  );

  const data = ffmpeg.FS("readFile", "output.mp4");
  return new Blob([data.buffer], { type: "video/mp4" });
}

// apps/web/src/pages/api/export.ts
import { spawn } from "child_process";
import { promises as fs } from "fs";
import { tmpdir } from "os";
import { join } from "path";

export default async function handler(req, res) {
  if (req.method !== "POST") return res.status(405).end();

  const { ir, ass, quality } = req.body;

  // 临时工作目录
  const workdir = await fs.mkdtemp(join(tmpdir(), "export-"));
  const assPath = join(workdir, "subs.ass");
  await fs.writeFile(assPath, ass);

  // Step 1: 写入 inputs.txt
  const list = ir.clips.map(c => `file '${c.src}'`).join("\n");
  await fs.writeFile(join(workdir, "inputs.txt"), list);

  // Step 2: 构建 ffmpeg 命令
  // 简单拼接 + 硬字幕
  const args = [
    "-f", "concat", "-safe", "0", "-i", "inputs.txt",
    "-vf", `subtitles=subs.ass:fontsdir=./fonts`,
    "-c:v", "libx264", "-preset", "medium", "-crf", "20",
    "-c:a", "aac", "-b:a", "192k",
    "output.mp4"
  ];

  const ff = spawn("ffmpeg", args, { cwd: workdir });
  ff.stderr.on("data", d => process.stdout.write(d));

  ff.on("close", async code => {
    if (code !== 0) return res.status(500).send("Export failed");
    const data = await fs.readFile(join(workdir, "output.mp4"));
    res.setHeader("Content-Type", "video/mp4");
    res.send(data);
  });
}

3. 时间轴 → ASS 生成器
function timelineToASS(ir: TimelineIR): string {
  const header = `
[Script Info]
PlayResX: ${ir.width}
PlayResY: ${ir.height}

[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, OutlineColour, BackColour, Bold, Italic, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Style: Default, Arial, 40, &H00FFFFFF, &H00000000, &H00000000, 0,0,1,2,2,2,20,20,20,1

[Events]
Format: Layer, Start, End, Style, Text
`.trim();

  const events = ir.texts.map(t => {
    return `Dialogue: 0,${ms2ass(t.start)},${ms2ass(t.end)},Default,{\\pos(${t.style.x},${t.style.y})}${t.text}`;
  }).join("\n");

  return header + "\n" + events;
}

function ms2ass(ms: number): string {
  const s = Math.floor(ms / 1000);
  const cs = Math.floor((ms % 1000) / 10);
  const h = String(Math.floor(s / 3600)).padStart(1, "0");
  const m = String(Math.floor((s % 3600) / 60)).padStart(2, "0");
  const sec = String(s % 60).padStart(2, "0");
  return `${h}:${m}:${sec}.${cs}`;
}

// apps/web/src/app/api/export/route.ts
// 后端导出 API，支持 SSE 进度推送（JSON 格式 {current, total}）

import { spawn } from "child_process";
import { promises as fs } from "fs";
import { tmpdir } from "os";
import { join } from "path";
import { NextRequest } from "next/server";

// SSE 进度推送
export async function GET() {
  const encoder = new TextEncoder();
  let controller: ReadableStreamDefaultController;

  const stream = new ReadableStream({
    start(ctrl) {
      controller = ctrl;
      controller.enqueue(encoder.encode(`data: ${JSON.stringify({status: "ready"})}\n\n`));
    },
  });

  // 保存 controller 以便 POST 使用
  (global as any).__exportController = controller;

  return new Response(stream, {
    headers: {
      "Content-Type": "text/event-stream",
      "Cache-Control": "no-cache",
      "Connection": "keep-alive",
    },
  });
}

// 导出视频 API
export async function POST(req: NextRequest) {
  const { ir, ass }: { ir: any; ass: string } = await req.json();

  const workdir = await fs.mkdtemp(join(tmpdir(), "export-"));
  const assPath = join(workdir, "subs.ass");
  await fs.writeFile(assPath, ass);

  const list = ir.clips.map((c: any) => `file '${c.src}'`).join("\n");
  const listPath = join(workdir, "inputs.txt");
  await fs.writeFile(listPath, list);

  const outPath = join(workdir, "output.mp4");

  const args = [
    "-f", "concat", "-safe", "0", "-i", listPath,
    "-vf", `subtitles=${assPath}`,
    "-c:v", "libx264", "-preset", "medium", "-crf", "20",
    "-c:a", "aac", "-b:a", "192k",
    outPath
  ];

  // 总时长（秒）
  const totalDuration = ir.clips.reduce((acc: number, c: any) => acc + c.duration / 1000, 0);

  return new Promise((resolve) => {
    const ff = spawn("ffmpeg", args);

    ff.stderr.on("data", (d) => {
      const msg = d.toString();
      const match = msg.match(/time=(\d+):(\d+):(\d+)\.(\d+)/);
      if (match) {
        const h = parseInt(match[1]);
        const m = parseInt(match[2]);
        const s = parseInt(match[3]);
        const current = h * 3600 + m * 60 + s;

        const payload = JSON.stringify({ current, total: totalDuration });
        const ctrl = (global as any).__exportController;
        if (ctrl) ctrl.enqueue(new TextEncoder().encode(`data: ${payload}\n\n`));
      }
    });

    ff.on("close", async (code) => {
      const ctrl = (global as any).__exportController;
      if (ctrl) ctrl.enqueue(new TextEncoder().encode(`data: ${JSON.stringify({status: "done"})}\n\n`));

      if (code !== 0) {
        resolve(new Response(JSON.stringify({ error: "FFmpeg failed" }), { status: 500 }));
        return;
      }
      const data = await fs.readFile(outPath);
      resolve(new Response(data, {
        headers: {
          "Content-Type": "video/mp4",
          "Content-Disposition": "attachment; filename=output.mp4"
        }
      }));
    });
  });
}

// 导出视频 API
export async function POST(req: NextRequest) {
  const { ir, ass }: { ir: any; ass: string } = await req.json();

  const workdir = await fs.mkdtemp(join(tmpdir(), "export-"));
  const assPath = join(workdir, "subs.ass");
  await fs.writeFile(assPath, ass);

  const list = ir.clips.map((c: any) => `file '${c.src}'`).join("\n");
  const listPath = join(workdir, "inputs.txt");
  await fs.writeFile(listPath, list);

  const outPath = join(workdir, "output.mp4");

  const args = [
    "-f", "concat", "-safe", "0", "-i", listPath,
    "-vf", `subtitles=${assPath}`,
    "-c:v", "libx264", "-preset", "medium", "-crf", "20",
    "-c:a", "aac", "-b:a", "192k",
    outPath
  ];

  // 总时长（秒）
  const totalDuration = ir.clips.reduce((acc: number, c: any) => acc + c.duration / 1000, 0);

  return new Promise((resolve) => {
    const ff = spawn("ffmpeg", args);

    ff.stderr.on("data", (d) => {
      const msg = d.toString();
      const match = msg.match(/time=(\d+):(\d+):(\d+)\.(\d+)/);
      if (match) {
        const h = parseInt(match[1]);
        const m = parseInt(match[2]);
        const s = parseInt(match[3]);
        const current = h * 3600 + m * 60 + s;

        const payload = JSON.stringify({ current, total: totalDuration });
        const ctrl = (global as any).__exportController;
        if (ctrl) ctrl.enqueue(new TextEncoder().encode(`data: ${payload}\n\n`));
      }
    });

    ff.on("close", async (code) => {
      const ctrl = (global as any).__exportController;
      if (ctrl) ctrl.enqueue(new TextEncoder().encode(`data: ${JSON.stringify({status: "done"})}\n\n`));

      if (code !== 0) {
        resolve(new Response(JSON.stringify({ error: "FFmpeg failed" }), { status: 500 }));
        return;
      }
      const data = await fs.readFile(outPath);
      resolve(new Response(data, {
        headers: {
          "Content-Type": "video/mp4",
          "Content-Disposition": "attachment; filename=output.mp4"
        }
      }));
    });
  });
}
