# OpenCut 部署脚本使用说明

本文档介绍如何使用OpenCut项目的自动化部署脚本。

## 📁 脚本文件

### 1. **完整部署脚本** (`deploy-opencut.sh`)
- 功能完整的部署脚本
- 包含详细的日志和错误处理
- 支持交互式操作
- 适合生产环境使用

### 2. **快速部署脚本** (`deploy-quick.sh`)
- 简化版部署脚本
- 一键部署，快速执行
- 适合开发和测试环境
- 执行速度快

## 🚀 使用方法

### 方法1: 使用完整部署脚本

```bash
# 在项目根目录执行
./deploy-opencut.sh
```

**特点：**
- 详细的部署步骤
- 完整的错误处理
- 交互式操作
- 部署状态检查
- 日志查看选项

### 方法2: 使用快速部署脚本

```bash
# 在项目根目录执行
./deploy-quick.sh
```

**特点：**
- 一键部署
- 执行速度快
- 自动处理所有步骤
- 适合频繁部署

## 📋 部署流程

### 完整部署流程

1. **本地项目检查**
   - 验证项目路径
   - 检查必要文件

2. **创建压缩包**
   - 保持项目完整性
   - 生成项目压缩包

3. **服务器准备**
   - 删除旧文件
   - 杀死占用端口的进程
   - 清理工作目录
   - 验证旧文件夹完全删除

4. **文件上传**
   - 上传压缩包到服务器
   - 验证上传状态

5. **项目部署**
   - 解压项目文件
   - 安装依赖（如需要）
   - 后台启动项目

6. **状态检查**
   - 检查端口状态
   - 验证进程运行
   - 查看部署日志

### 快速部署流程

1. **创建压缩包** → 排除node_modules等文件
2. **上传到服务器** → 使用scp命令
3. **服务器部署** → 自动执行所有部署步骤
4. **状态验证** → 检查端口和进程状态

## 🔧 环境要求

- Linux 系统

## 📊 排除文件

部署时会自动排除以下文件：

```
.git/*                 # Git版本控制
.DS_Store              # macOS系统文件
*.tmp                  # 临时文件
```

**注意**: 为了确保项目在服务器上正常运行，以下文件会被包含在压缩包中：
- `node_modules/` - 项目依赖包
- `.next/` - Next.js构建文件
- `out/` - 输出目录
- `dist/` - 分发目录
- `*.log` - 日志文件
- `.env.local` - 本地环境变量
- `.env.production` - 生产环境变量

## 🚨 注意事项

### 安全提醒
1. **SSH密钥**: 确保已配置SSH密钥认证
2. **权限管理**: 服务器用户需要有sudo权限
3. **端口冲突**: 确保3000端口未被其他服务占用
4. **磁盘空间**: 确保服务器有足够的存储空间

### 部署前检查
1. 确认本地代码已提交
2. 检查服务器网络连接
3. 验证SSH连接正常
4. 确认服务器环境配置

### 常见问题

#### 1. SSH连接失败
```bash
# 测试SSH连接
ssh mf@39.105.24.90

# 检查SSH配置
ssh -v mf@39.105.24.90
```

#### 2. 权限不足
```bash
# 检查脚本权限
ls -la deploy-opencut.sh

# 添加执行权限
chmod +x deploy-opencut.sh
```

#### 3. 端口被占用
```bash
# 在服务器上检查端口状态
sudo netstat -tlnp | grep :3000

# 杀死占用进程
sudo kill -9 <PID>
```
