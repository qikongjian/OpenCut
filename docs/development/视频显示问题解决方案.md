# 🎬 SmartCut Frontend 视频显示问题解决方案

## 🔍 问题描述

在部署到服务器 `39.105.24.90` 后，发现以下问题：
- ✅ 时间轴正常显示字幕元素
- ❌ 时间轴显示视频元素但预览区域不显示视频内容
- ❌ 浏览器控制台显示视频加载成功但实际不可见

## 📊 问题分析

### 根本原因
1. **Blob URL失效**: 视频文件使用 `blob:` URL，在服务器环境中无法正确访问
2. **文件存储问题**: 视频文件只存在于浏览器本地存储，未上传到服务器
3. **容器健康状态**: 应用容器处于 `unhealthy` 状态

### 技术细节
```
视频加载流程:
本地文件 → Blob URL → 浏览器显示 ✅
本地文件 → Blob URL → 服务器访问 ❌
```

## 🛠️ 解决方案

### 方案1: 实现服务器端文件上传 (推荐)

#### 1.1 创建文件上传API
```typescript
// apps/web/src/app/api/upload/route.ts
export async function POST(request: NextRequest) {
  const formData = await request.formData();
  const file = formData.get('file') as File;
  
  if (!file) {
    return NextResponse.json({ error: 'No file provided' }, { status: 400 });
  }
  
  // 保存文件到服务器
  const uploadDir = '/app/uploads';
  const fileName = `${Date.now()}-${file.name}`;
  const filePath = path.join(uploadDir, fileName);
  
  const bytes = await file.arrayBuffer();
  await fs.writeFile(filePath, Buffer.from(bytes));
  
  return NextResponse.json({
    url: `/uploads/${fileName}`,
    fileName,
    size: file.size
  });
}
```

#### 1.2 修改前端上传逻辑
```typescript
// 在添加媒体项时上传到服务器
const uploadToServer = async (file: File) => {
  const formData = new FormData();
  formData.append('file', file);
  
  const response = await fetch('/api/upload', {
    method: 'POST',
    body: formData
  });
  
  if (!response.ok) {
    throw new Error('Upload failed');
  }
  
  return await response.json();
};
```

#### 1.3 更新视频播放器组件

```typescript
// 修改 VideoPlayer 组件处理服务器URL
const VideoPlayer = ({ src, ...props }) => {
  const videoSrc = src.startsWith('blob:')

    : src.startsWith('/uploads/')
```

```typescript
// 将blob数据转换为base64存储
const blobToBase64 = (blob: Blob): Promise<string> => {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => resolve(reader.result as string);
    reader.onerror = reject;
    reader.readAsDataURL(blob);
  });
};
```

### 方案3: 配置优化

#### 3.1 Nginx配置
```nginx
# 添加到 nginx.conf
location /uploads/ {
    alias /app/uploads/;
    expires 1y;
    add_header Cache-Control "public, immutable";
    
    # 支持视频文件
    location ~* \.(mp4|webm|ogg|avi|mov)$ {
        add_header Content-Type video/mp4;
    }
}
```

#### 3.2 Docker配置
```yaml
# docker-compose.prod.yml
services:
  opencut-app:
    volumes:
      - ./uploads:/app/uploads

      interval: 30s
      timeout: 10s
      retries: 3
```
