# AI智能剪辑功能 - 测试执行清单

## 🚀 快速测试清单 (15分钟)

### 环境准备
- [ ] 项目已启动 (`npm run dev`)
- [ ] 浏览器已打开编辑器页面
- [ ] 开发者工具已打开 (F12)
- [ ] 网络连接正常

### 核心功能测试 (P0级别)

#### 1. 基础访问测试
- [ ] 点击左侧媒体面板
- [ ] 找到并点击"AI剪辑"标签 (🤖图标)
- [ ] 验证面板正常显示
- [ ] 检查"生成AI剪辑计划"按钮可见

**预期**: AI剪辑面板正常显示，空状态界面完整

#### 2. 剪辑计划生成测试
- [ ] 确保有活动项目 (如无则创建)
- [ ] 点击"生成AI剪辑计划"按钮
- [ ] 等待1-2秒处理完成
- [ ] 验证成功提示消息
- [ ] 检查剪辑计划界面显示

**预期**: 生成包含3个片段的剪辑计划

#### 3. 剪辑计划数据验证
- [ ] 检查版本名称: "主剪辑版 (Final Cut)"
- [ ] 验证片段1: 3.4s, SCENE 1, 淡入
- [ ] 验证片段2: 7.8s, SCENE 1, 硬切  
- [ ] 验证片段3: 7.6s, SCENE 1, 硬切
- [ ] 检查剪辑理由完整显示

**预期**: 所有数据准确无误

#### 4. 一键剪辑执行测试
- [ ] 点击"一键剪辑"按钮
- [ ] 观察按钮状态变为"执行中..."
- [ ] 检查进度条正常显示
- [ ] 验证处理状态实时更新
- [ ] 等待执行完成 (3-5秒)

**预期**: 执行成功，显示成功提示

#### 5. 时间轴结果验证
- [ ] 切换到底部时间轴面板
- [ ] 检查生成3个AI片段
- [ ] 验证绿色左边框标识
- [ ] 检查Bot图标显示
- [ ] 确认"AI剪辑-"前缀命名

**预期**: 时间轴正确显示AI生成的片段

#### 6. 片段选择交互

- [ ] 确认选择状态切换

#### 7. 视频缩略图预览测试

**预期**: 缩略图显示正确，预览功能正常

#### 8. 中央视频播放器测试

#### 10. 清空计划测试

- **Blocker**: 立即通知开发团队
- **Critical**: 4小时内响应
- **Major**: 24小时内响应
