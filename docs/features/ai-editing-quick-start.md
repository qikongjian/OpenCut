# AI智能剪辑 - 快速上手指南

## 🚀 5分钟快速体验

### 前提条件
- ✅ 项目已启动运行
- ✅ 浏览器已打开编辑器页面

### 🎯 快速测试步骤

#### 步骤1: 进入AI剪辑面板
1. 在编辑器左侧找到 **媒体面板**
2. 点击 **"AI剪辑"** 标签 (🤖图标)
3. 看到AI剪辑面板界面

#### 步骤2: 生成AI剪辑计划
1. 点击绿色的 **"生成AI剪辑计划"** 按钮
2. 等待1-2秒，系统生成剪辑方案
3. 查看生成的剪辑计划详情

#### 步骤3: 查看剪辑方案
浏览生成的3个剪辑片段：
- **片段1**: 雨夜开场，建立氛围
- **片段2**: 引入对抗者，权力展示  
- **片段3**: 内心独白，情感深化

每个片段都包含：
- 📝 详细的剪辑理由
- 🎬 转场效果设计
- ⏱️ 精确的时间码
- 🎭 情感和节奏分析

#### 步骤4: 执行一键剪辑
1. 点击橙色的 **"一键剪辑"** 按钮
2. 观察实时进度条和处理状态
3. 等待3-5秒完成执行

#### 步骤5: 查看剪辑结果
1. 切换到底部的 **时间轴面板**
2. 查看自动生成的3个片段
3. 注意AI片段的特殊标识：
   - 🟢 **绿色左边框**
   - 🤖 **Bot图标**
   - 🏷️ **"AI剪辑-"前缀**

## 🔍 功能详解

### 剪辑计划数据
基于真实AI视频分析结果，包含：

#### 专业剪辑理论
- **情感优先级**: 忧郁、沉思、对比张力
- **故事优先级**: 场景建立、角色引入、主题揭示
- **节奏优先级**: 缓慢压抑、能量积蓄、内心留白
- **镜头语言**: 全景建立、权力关系、窥视视角

#### 技术细节
- **时间码精确**: 毫秒级的时间控制
- **转场设计**: 淡入、J-Cut、硬切等专业转场
- **音效建议**: 雨声、混响、音频同步
- **视觉增强**: 色彩分级、对比度调整

### 智能匹配机制
系统会自动处理媒体文件匹配：

1. **精确匹配**: 优先匹配URL和文件名
2. **智能替代**: 使用现有媒体文件作为替代
3. **友好提示**: 提醒用户导入相关文件
4. **错误处理**: 优雅处理各种异常情况

## 💡 使用技巧

### 最佳实践
1. **项目准备**: 先创建项目再使用AI剪辑
2. **媒体导入**: 导入一些视频文件获得更好效果
3. **结果调整**: AI剪辑后可手动微调
4. **多次尝试**: 可以清空计划重新生成

### 常见问题
- **Q**: 为什么没有生成片段？
- **A**: 检查是否有活动项目，尝试刷新页面

- **Q**: 片段时长不对怎么办？
- **A**: 可以在时间轴中手动调整片段长度

- **Q**: 如何重新生成计划？
- **A**: 点击"清空计划"按钮，然后重新生成
