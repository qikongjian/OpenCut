# AI智能剪辑 - 视频预览功能使用指南

## 🎯 功能概述

AI智能剪辑功能现已支持视频缩略图预览和中央播放器预览，让用户能够：
1. **直观查看**: 通过缩略图快速识别视频内容
2. **即时预览**: 点击缩略图在中央播放器预览视频
3. **真实剪辑**: 基于video_url进行真实的视频剪辑操作

## 🖼️ 视频缩略图功能

### 功能特点
- **自动生成**: 基于视频源自动生成缩略图
- **时间定位**: 显示片段在源视频中的具体时间点
- **交互预览**: 点击缩略图即可预览视频
- **状态反馈**: 加载状态和错误提示

### 使用方法
1. **查看缩略图**: 在剪辑计划中每个片段都会显示80x45的缩略图
2. **时间信息**: 缩略图右下角显示时间码
3. **预览提示**: 鼠标悬停显示"点击预览视频"提示
4. **点击预览**: 点击缩略图在中央播放器开始预览

### 技术实现
```typescript
// 缩略图组件使用
<VideoThumbnail
  videoUrl={clip.video_url}
  startTime={timecodeToSeconds(clip.source_in_timecode)}
  width={80}
  height={45}
  onPreview={(url, time) => handleVideoPreview(url, time)}
/>
```

## 🎬 中央视频播放器

### 播放器功能
- **视频播放**: 支持播放/暂停控制
- **进度控制**: 可拖拽的进度条
- **音量调节**: 音量滑块和静音切换
- **全屏播放**: 支持全屏模式
- **时间显示**: 当前时间和总时长显示
- **重置功能**: 一键重置到片段开始时间

### 控制界面

### 使用方法
1. **开始预览**: 点击任意片段缩略图
2. **播放控制**: 点击播放/暂停按钮或视频中央
3. **进度跳转**: 拖拽进度条到指定位置
4. **音量调节**: 使用音量滑块或点击静音按钮
5. **重置播放**: 点击重置按钮回到片段开始时间
6. **全屏观看**: 点击全屏按钮进入全屏模式
7. **关闭预览**: 点击右上角关闭按钮

## ⚙️ 真实视频剪辑

### 剪辑原理
- **源视频URL**: 使用timeline_clips中的video_url字段
- **精确时间**: 基于source_in_timecode和source_out_timecode
- **真实剪辑**: 不再使用替代文件，直接处理指定视频
- **元数据保留**: 保留原始视频URL和源片段信息

### 剪辑流程
```
用户点击"一键剪辑"
    ↓
遍历timeline_clips数组
    ↓
提取每个clip的video_url
    ↓
计算精确的时间段 (source_in → source_out)
    ↓
创建MediaElement with 原始video_url
    ↓
添加到时间轴 with AI标识
```

### 时间轴展示
剪辑完成后，时间轴中的片段将显示：
- **绿色边框**: AI生成片段的视觉标识
- **Bot图标**: 表示AI智能剪辑
- **详细命名**: "AI剪辑-v1_clip_001 (vid_clip_001_pachinko_style_rainy_window)"
- **源URL**: mediaUrl字段保存原始video_url

## 🔧 技术架构

### 组件结构
```
AI剪辑面板 (ai-editing-panel.tsx)
├── 视频缩略图 (video-thumbnail.tsx)
│   ├── 缩略图生成 (Canvas API)
│   ├── 预览触发
│   └── 状态管理
├── 视频预览播放器 (video-preview-player.tsx)
│   ├── 播放控制
│   ├── 进度管理
│   └── 音量控制
└── 状态管理
    ├── AI剪辑Store (ai-editing-store.ts)
    ├── 视频预览Store (video-preview-store.ts)
    └── 时间轴Store (timeline-store.ts)
```

### 数据流
```
Mock数据 (ai-editing-mock-data.ts)
    ↓
AI剪辑Store加载数据
    ↓
面板显示剪辑计划 + 缩略图
    ↓
用户点击缩略图
    ↓
视频预览Store管理播放状态
    ↓
中央播放器显示视频
    ↓
用户执行一键剪辑
    ↓
基于video_url创建时间轴元素
```

## 📊 性能优化

### 缩略图优化
- **懒加载**: 只在需要时生成缩略图
- **缓存机制**: 避免重复生成相同缩略图
- **尺寸控制**: 固定80x45尺寸减少内存占用
- **错误处理**: 优雅处理视频加载失败

### 播放器优化
- **预加载**: 使用preload="metadata"减少加载时间
- **内存管理**: 及时清理视频资源
- **状态同步**: 高效的状态更新机制
- **CORS优化**: 移除crossOrigin避免跨域问题

## 💡 最佳实践

### 使用建议
1. **预览确认**: 执行剪辑前先预览关键片段
2. **质量检查**: 注意AI标记的质量问题
3. **时间验证**: 确认时间段符合预期
4. **源文件管理**: 确保video_url可访问

### 注意事项
1. **网络依赖**: 视频预览需要稳定的网络连接
2. **浏览器兼容**: 某些视频格式可能有兼容性问题
3. **性能影响**: 大量缩略图可能影响页面性能
4. **跨域限制**: 某些视频源可能有跨域限制
