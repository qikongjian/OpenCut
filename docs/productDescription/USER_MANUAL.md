# 📖 OpenCut 用户使用手册

> **OpenCut** - 专业级 Web 视频编辑平台，100%隐私保护，完全免费，AI 驱动的智能剪辑体验

---

## 🎯 产品概述

### 核心价值

- **🔒 隐私优先**: 所有视频处理在本地完成，数据不离开您的设备
- **💰 完全免费**: 无订阅费用、无水印、无功能限制
- **🤖 AI 智能**: 一键 AI 剪辑，自动生成专业视频
- **⚡ 高性能**: 基于现代 Web 技术，流畅的编辑体验
- **🌐 跨平台**: 支持所有现代浏览器，无需安装

### 系统要求

- **推荐浏览器**: Chrome 90+, Firefox 85+, Safari 14+
- **内存要求**: 8GB+ RAM (推荐)
- **网络**: 稳定的互联网连接 (用于 AI 功能)
- **存储**: 足够的本地存储空间

## 🚀 快速开始

### 1. 访问平台

打开浏览器访问：`https://opencut.app`

### 2. 创建项目

1. 点击"新建项目"按钮
2. 输入项目名称
3. 选择视频尺寸和帧率
4. 点击"创建"开始编辑

### 3. 导入媒体

- **拖拽上传**: 直接将视频/音频/图片文件拖拽到媒体面板
- **点击上传**: 点击媒体面板的"+"按钮选择文件
- **支持格式**: MP4, MOV, AVI, WebM, MP3, WAV, JPG, PNG 等

## 🎥 基础编辑操作

### 视频编辑

1. **添加视频到时间轴**

   - 从媒体面板拖拽视频到时间轴
   - 视频会自动对齐到轨道

2. **调整视频长度**

   - 拖拽视频元素的边缘调整长度
   - 使用分割工具精确剪切

3. **移动和排序**
   - 拖拽视频元素改变位置
   - 多个视频可以排列组合

### 音频编辑

1. **添加背景音乐**

   - 拖拽音频文件到音频轨道
   - 调整音量和淡入淡出效果

2. **音频同步**
   - 对齐音频和视频时间点
   - 使用波形显示精确调整

### 文字和字幕

1. **添加文字**

   - 点击文字标签页
   - 选择文字样式拖拽到时间轴
   - 在属性面板编辑内容和样式

2. **AI 自动字幕**
   - 点击字幕标签页
   - 选择语言和字幕样式
   - AI 自动识别语音生成字幕

## 🤖 AI 智能功能

### AI 一键剪辑

**使用步骤**:

1. 点击"AI 剪辑"标签页
2. 上传或选择要剪辑的视频
3. 选择剪辑风格和时长
4. 点击"一键剪辑"
5. AI 自动分析并生成剪辑方案
6. 预览并应用到时间轴

**剪辑风格**:

- **快节奏**: 适合音乐视频、运动场景
- **慢节奏**: 适合风景、纪录片
- **平衡**: 通用剪辑风格
- **自定义**: 根据内容智能选择

### AI 自动字幕

**功能特点**:

- 支持多种语言识别
- 自动时间轴同步
- 可编辑字幕内容
- 多种字幕样式

**使用方法**:

1. 选择包含语音的视频
2. 点击"生成字幕"
3. 选择识别语言
4. 等待 AI 处理完成
5. 字幕自动添加到时间轴

## 🛠️ 故障排除

### 常见问题

**Q: 视频无法播放或显示黑屏**
A: 检查视频格式是否支持，尝试转换为 MP4 格式

**Q: 导出速度很慢**
A: 降低导出质量，关闭其他浏览器标签页，确保足够内存

**Q: AI 功能无法使用**
A: 检查网络连接，确保浏览器支持现代 Web API

**Q: 项目无法保存**
A: 检查浏览器存储权限，清理浏览器缓存

### 性能优化建议

1. **使用推荐浏览器**: Chrome 或 Firefox 最新版本
2. **充足内存**: 至少 8GB RAM，推荐 16GB
3. **关闭无关标签**: 释放浏览器内存
4. **定期清理**: 清理浏览器缓存和临时文件
5. **网络稳定**: 确保稳定的网络连接
