## 🎬 基础操作流程

### 1. 创建项目
```
新建项目 → 输入名称 → 选择尺寸 → 开始编辑
```

### 2. 导入媒体
```
拖拽文件到媒体面板 → 自动处理 → 显示在媒体库
```

### 3. 添加到时间轴
```
从媒体面板拖拽 → 放到时间轴轨道 → 自动对齐
```

### 4. 基础编辑
```
选择元素 → 拖拽调整位置 → 拖拽边缘调整长度
```

### 5. 导出视频
```
点击导出按钮 → 选择质量格式 → 开始导出 → 下载
```

## 🤖 AI功能快速使用

### AI一键剪辑
1. 点击 `AI剪辑` 标签页
2. 上传视频或选择已有视频
3. 选择剪辑风格和时长
4. 点击 `一键剪辑`
5. 等待AI处理完成
6. 预览并应用到时间轴

### AI自动字幕
1. 选择包含语音的视频
2. 点击 `字幕` 标签页
3. 点击 `生成字幕`
4. 选择识别语言
5. 等待处理完成
6. 字幕自动添加到时间轴

## 🎯 时间轴操作

### 元素操作
- **选择**: 点击元素
- **多选**: Ctrl + 点击
- **移动**: 拖拽元素
- **调整长度**: 拖拽元素边缘
- **分割**: 播放头定位 + S键
- **删除**: 选中 + Delete键

### 轨道管理
- **添加轨道**: 右键时间轴 → 添加轨道
- **删除轨道**: 右键轨道 → 删除轨道
- **轨道高度**: 拖拽轨道分隔线
- **轨道静音**: 点击轨道静音按钮

### 时间轴缩放
- **放大**: 鼠标滚轮向上 或 + 按钮
- **缩小**: 鼠标滚轮向下 或 - 按钮
- **适应窗口**: 双击时间轴标尺
- **精确缩放**: 使用缩放滑块

## 📤 导出设置

### 质量选项
| 质量 | 分辨率 | 用途 |
|------|--------|------|
| 快速 | 720p | 快速预览 |

### 格式选项
| 格式 | 特点 | 适用场景 |
|------|------|----------|
| MP4 | 通用兼容 | 大多数平台 |
| WebM | Web优化 | 网页播放 |

### 导出流程
1. 点击 `导出` 按钮
2. 选择质量和格式
3. 设置文件名
4. 点击 `开始导出`
5. 等待处理完成
6. 自动下载文件

## 🔧 常见问题解决

### 性能问题
- **关闭其他标签页**: 释放内存
- **降低预览质量**: 提高响应速度
- **清理浏览器缓存**: 释放存储空间
- **使用推荐浏览器**: Chrome或Firefox

### 导入问题
- **检查文件格式**: 确保支持的格式
- **文件大小限制**: 避免过大文件
- **网络连接**: 确保网络稳定
- **浏览器权限**: 允许文件访问

### 导出问题
- **存储空间**: 确保足够空间
- **内存不足**: 关闭其他应用
- **网络问题**: 检查网络连接
- **格式兼容**: 选择兼容格式
