# 🎬 SmartCut Frontend 时间轴播放和操作功能总结

## 📋 概述

SmartCut Frontend 的时间轴系统是整个视频编辑器的核心组件，提供了专业级的多轨道编辑、精确的播放控制和丰富的交互操作功能。系统采用现代化的 React + TypeScript 架构，结合 Zustand 状态管理，实现了高性能和流畅的用户体验。

## 🎮 播放控制系统

### 核心播放功能

**播放状态管理** (`playback-store.ts`):

- **播放/暂停**: 支持一键切换播放状态
- **精确定位**: 基于帧的精确 seek 功能
- **播放速度**: 0.1x - 2.0x 可调节播放速度
- **音量控制**: 0-100% 音量调节和静音功能
- **循环播放**: 到达内容末尾自动停止在最后一帧

**播放头控制** (`timeline-playhead.tsx`):

- **实时同步**: 播放头与当前时间实时同步
- **拖拽控制**: 支持拖拽播放头进行 scrubbing
- **自动滚动**: 播放时自动滚动保持播放头可见
- **性能优化**: 使用 RAF 和硬件加速优化渲染

### 播放同步机制

**多媒体同步**:

- **视频同步**: 所有视频元素与播放头精确同步
- **音频同步**: 音频播放与时间轴完美对齐
- **帧精确**: 基于项目 FPS 的帧级精确控制
- **事件驱动**: 通过自定义事件实现组件间同步

**播放范围控制**:

- **内容边界**: 自动检测实际内容长度
- **智能停止**: 在内容结束前一帧停止播放
- **重播功能**: 到达末尾后可重新开始播放

### 播放头精确控制

**帧级精确定位**:

```typescript
// 基于项目FPS的帧对齐
const snapTimeToFrame = (time: number, fps: number) => {
  const frameTime = 1 / fps
  return Math.round(time / frameTime) * frameTime
}
```

**播放头位置计算**:

### 拖拽系统实现

**拖拽状态管理**:

- **开始拖拽**: 记录初始位置和偏移量
- **拖拽过程**: 实时计算新位置并应用吸附
- **结束拖拽**: 提交最终位置并清理状态

**碰撞检测算法**:

```typescript
const hasOverlap = (element1, element2) => {
  const start1 = element1.startTime
  const end1 = start1 + element1.effectiveDuration
  const start2 = element2.startTime
  const end2 = start2 + element2.effectiveDuration

  return start1 < end2 && end1 > start2
}
```

### 吸附算法优化

**多层级吸附**:

1. **帧吸附**: 优先级最高，确保帧对齐
2. **元素吸附**: 吸附到其他元素边缘
3. **播放头吸附**: 吸附到当前播放位置
4. **轨道边界**: 吸附到轨道开始/结束

**性能优化策略**:

- 使用空间索引加速碰撞检测
- 缓存计算结果避免重复计算
- 限制吸附检测范围提高性能
