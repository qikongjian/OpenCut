# 🎯 时间轴拖动播放控制优化

## 📋 问题描述

在原有的时间轴实现中，当用户拖动时间轴上的播放头或在预览面板中拖动进度条时，视频会继续播放，导致以下问题：

1. **播放冲突**：拖动过程中播放头位置和拖动位置产生冲突
2. **用户体验差**：拖动时视频继续播放，无法精确定位到想要的帧
3. **不符合专业编辑器习惯**：专业视频编辑器通常在拖动时暂停播放

## 🎯 解决方案

实现了智能的播放状态控制机制：

### 核心逻辑
- **拖动开始时**：记录当前播放状态并自动暂停播放
- **拖动过程中**：视频保持暂停状态，允许精确的帧定位
- **拖动结束时**：根据拖动前的状态决定是否恢复播放

### 实现细节

#### 1. 时间轴播放头拖动控制 (`use-timeline-playhead.ts`)

**新增状态管理**：
```typescript
// 记录拖动前的播放状态，用于拖动结束后恢复
const [wasPlayingBeforeScrub, setWasPlayingBeforeScrub] = useState(false);
```

**播放头拖动开始**：
```typescript
const handlePlayheadMouseDown = useCallback((e: React.MouseEvent) => {
  // 记录当前播放状态并暂停播放
  const { isPlaying, pause } = usePlaybackStore.getState();
  setWasPlayingBeforeScrub(isPlaying);
  if (isPlaying) {
    pause();
  }
  
  setIsScrubbing(true);
  handleScrub(e);
}, [duration, zoomLevel]);
```

**时间轴标尺拖动开始**：

**拖动结束恢复**：
```typescript
const onMouseUp = (e: MouseEvent) => {
  setIsScrubbing(false);
  if (scrubTime !== null) seek(scrubTime);
  setScrubTime(null);

  // 拖动结束后恢复播放状态
  if (wasPlayingBeforeScrub) {
    const { play } = usePlaybackStore.getState();
    play();
  }
  setWasPlayingBeforeScrub(false);
```


## ✨ 优化效果

### 用户体验提升
1. **精确定位**：拖动时视频暂停，用户可以精确定位到想要的帧
2. **智能恢复**：只有在拖动前正在播放的情况下才会在拖动结束后恢复播放
3. **专业体验**：符合专业视频编辑器的操作习惯

### 技术优势
1. **状态一致性**：确保播放状态在拖动过程中的一致性
2. **性能优化**：避免拖动过程中的播放冲突，减少不必要的渲染
3. **代码清晰**：逻辑清晰，易于维护和扩展
