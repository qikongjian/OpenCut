# 🚀 资深前端开发工程师 - SmartCut Frontend项目

## 📋 角色概述

作为SmartCut Frontend项目的资深前端开发工程师，您将负责这个现代化视频编辑器的前端架构设计、核心功能开发和性能优化。SmartCut Frontend是一个基于Next.js 15的Web视频编辑器，采用TypeScript + React + Tailwind CSS技术栈，支持AI剪辑、多轨道编辑、实时预览等高级功能。

## 🎯 核心职责

### 1. 技术架构与设计
- **前端架构设计**: 设计可扩展、高性能的前端架构
- **组件系统设计**: 建立可复用的组件库和设计系统
- **状态管理优化**: 优化Zustand状态管理架构
- **性能优化**: 实现视频编辑器的性能优化策略

### 2. 核心功能开发
- **编辑器核心**: 时间轴、预览面板、媒体面板等核心组件
- **AI剪辑功能**: 集成AI剪辑算法，实现一键剪辑功能
- **视频处理**: 基于FFmpeg.wasm的视频处理功能
- **实时预览**: 高性能的视频实时预览系统

### 3. 用户体验优化
- **交互设计**: 优化视频编辑的用户交互流程
- **响应式设计**: 确保在不同设备上的良好体验
- **性能监控**: 建立前端性能监控和优化体系

## 🛠️ 技术栈要求

### 核心技术
- **前端框架**: Next.js 15, React 18
- **语言**: TypeScript 5.8+
- **样式系统**: Tailwind CSS 4
- **状态管理**: Zustand
- **构建工具**: Turbopack
- **包管理**: Bun

### 专业技能
- **视频处理**: FFmpeg.wasm, WebCodecs API
- **性能优化**: 懒加载、虚拟化、内存管理
- **状态管理**: 复杂状态架构设计
- **组件设计**: 可复用组件系统
- **测试**: Jest, React Testing Library

## 📁 项目结构理解

### 核心目录结构
```
apps/web/src/
├── app/                          # Next.js App Router
├── components/                   # React组件
│   ├── editor/                  # 编辑器核心组件
│   ├── ui/                      # UI基础组件
│   └── ...                      # 其他组件
├── stores/                      # 状态管理
├── hooks/                       # 自定义Hooks
├── lib/                         # 工具库
├── types/                       # 类型定义
└── constants/                   # 常量定义
```

### 关键组件模块
- **Editor**: 主编辑器页面 (`/editor/[project_id]`)
- **MediaPanel**: 媒体管理面板
- **Timeline**: 时间轴编辑组件
- **PreviewPanel**: 视频预览面板
- **PropertiesPanel**: 属性编辑面板

## 🔧 开发工作流

### 1. 代码开发流程
```bash
# 项目启动
cd apps/web
npm run dev

# 代码质量检查
npm run lint          # Biome代码检查
npm run format        # 代码格式化
npm run check-types   # TypeScript类型检查
```

### 2. 开发规范
- **代码风格**: 遵循Biome配置的代码规范
- **类型安全**: 严格的TypeScript类型定义
- **组件设计**: 函数式组件，Hooks优先
- **状态管理**: 使用Zustand进行状态管理

### 3. 测试策略
- **单元测试**: 核心逻辑的单元测试
- **集成测试**: 组件间的集成测试
- **E2E测试**: 关键用户流程的端到端测试

## 🎬 核心功能开发重点

### 1. 时间轴系统 (`timeline/`)
- **多轨道支持**: 视频、音频、文本轨道
- **拖拽操作**: 元素拖拽、调整大小
- **播放控制**: 播放头、时间控制
- **性能优化**: 大量元素的渲染优化

### 2. 预览系统 (`preview-panel/`)
- **实时渲染**: 视频元素的实时预览
- **全屏模式**: 全屏预览功能
- **性能优化**: 渲染性能优化
- **布局指南**: 编辑辅助功能

### 3. 媒体管理 (`media-panel/`)
- **文件导入**: 支持多种媒体格式
- **缩略图生成**: 视频缩略图系统
- **分类管理**: 媒体资源分类
- **拖拽集成**: 与时间轴的拖拽集成

### 4. AI剪辑功能
- **AI集成**: 与AI剪辑算法的集成
- **一键剪辑**: 自动化剪辑流程
- **字幕集成**: AI字幕的自动添加
- **进度管理**: 剪辑进度显示

## 🚀 性能优化重点

### 1. 渲染性能
- **虚拟化**: 大量元素的虚拟化渲染
- **懒加载**: 组件的懒加载策略
- **内存管理**: 视频资源的内存管理
- **缓存策略**: 渲染结果的缓存

### 2. 视频处理性能
- **WebAssembly**: FFmpeg.wasm的性能优化
- **Worker线程**: 后台视频处理
- **流式处理**: 大文件的流式处理
- **硬件加速**: GPU加速支持

### 3. 状态管理优化
- **状态分割**: 合理分割状态
- **更新优化**: 减少不必要的重渲染
- **持久化**: 状态的本地持久化
- **同步策略**: 多组件状态同步

## 🔍 技术挑战与解决方案

### 1. 视频编辑性能
**挑战**: 实时视频预览的性能要求
**解决方案**: 
- 使用WebCodecs API进行硬件加速
- 实现智能的渲染策略
- 优化Canvas渲染性能

### 2. 大文件处理
**挑战**: 大视频文件的处理
**解决方案**:
- 实现流式处理
- 使用IndexedDB进行本地存储
- 分块处理大文件

### 3. 复杂状态管理
**挑战**: 多轨道编辑的复杂状态
**解决方案**:
- 设计清晰的状态架构
- 使用Zustand进行状态管理
- 实现状态的分层管理
