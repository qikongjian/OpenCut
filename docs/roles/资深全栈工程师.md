# 🚀 资深全栈工程师 - SmartCut Frontend 项目

## 📋 角色概述

作为 SmartCut Frontend 项目的资深全栈工程师，您将负责这个现代化 Web 视频编辑器的全栈架构设计、核心功能开发和系统优化。SmartCut Frontend 是一个基于 Next.js 15 的全栈 Web 应用，采用 TypeScript + React + PostgreSQL + Python 技术栈，支持 AI 剪辑、多轨道编辑、实时预览、语音转录等高级功能。

## 🎯 关键技术挑战

### 1. 大规模数据处理

**挑战描述**: 处理 GB 级视频文件而不崩溃
**技术方案**:

```typescript
// 流式文件处理示例
async function processLargeVideo(file: File) {
  const chunkSize = 1024 * 1024 // 1MB chunks
  const chunks = Math.ceil(file.size / chunkSize)

  for (let i = 0; i < chunks; i++) {
    const start = i * chunkSize
    const end = Math.min(start + chunkSize, file.size)
    const chunk = file.slice(start, end)

    await processChunk(chunk)
    updateProgress((i + 1) / chunks)
  }
}
```

### 2. 实时状态同步

**挑战描述**: 多组件间的复杂状态同步
**技术方案**:

```typescript
// Zustand状态管理示例
interface TimelineState {
  tracks: Track[]
  currentTime: number
  isPlaying: boolean
  selectedElements: string[]
}

const useTimelineStore = create<TimelineState>((set, get) => ({
  tracks: [],
  currentTime: 0,
  isPlaying: false,
  selectedElements: [],

  // 复杂状态更新逻辑
  updateElementPosition: (elementId: string, newPosition: number) => {
    set((state) => ({
      tracks: state.tracks.map((track) => ({
        ...track,
        elements: track.elements.map((element) =>
          element.id === elementId
            ? { ...element, startTime: newPosition }
            : element
        ),
      })),
    }))
  },
}))
```

### 3. 零知识加密

**挑战描述**: 客户端加密保护用户隐私
**技术方案**:

```typescript
// 零知识加密实现
export async function encryptWithRandomKey(data: ArrayBuffer) {
  // 生成随机密钥
  const key = await crypto.subtle.generateKey(
    { name: 'AES-GCM', length: 256 },
    true,
    ['encrypt', 'decrypt']
  )

  // 生成随机IV
  const iv = crypto.getRandomValues(new Uint8Array(12))

  // 加密数据
  const encryptedData = await crypto.subtle.encrypt(
    { name: 'AES-GCM', iv },
    key,
    data
  )

  // 导出密钥
  const exportedKey = await crypto.subtle.exportKey('raw', key)

  return {
    encryptedData: new Uint8Array(encryptedData),
    key: new Uint8Array(exportedKey),
    iv,
  }
}
```
