# postMessage 内存限制详解

## 概述

postMessage 是浏览器中用于跨窗口、跨 iframe 通信的重要 API。在实际应用中，特别是传输大文件数据时，了解其内存限制至关重要。

## 理论限制

### 1. 浏览器限制

| 浏览器 | 理论限制 | 实际安全限制 | 备注 |
|--------|----------|--------------|------|
| Chrome | ~2GB | 50MB | 最稳定 |
| Firefox | ~2GB | 50MB | 性能较好 |
| Safari | ~1GB | 30MB | 限制较严格 |
| Edge | ~2GB | 50MB | 基于 Chromium |

### 2. 数据类型限制

## 解决方案

### 1. 分块传输方案

```typescript
// apps/web/src/lib/postmessage-chunked-transfer.ts
export class ChunkedPostMessageTransfer {
  private chunkSize: number;
  private targetOrigin: string;
  private timeout: number;

  constructor(chunkSize = 5 * 1024 * 1024, targetOrigin = '*', timeout = 10000) {
    this.chunkSize = chunkSize; // 5MB 每块
    this.targetOrigin = targetOrigin;
    this.timeout = timeout;
  }

  // 分块传输大文件
  async transferLargeData(data: ArrayBuffer, onProgress?: (progress: number) => void): Promise<boolean> {
    try {
      const totalChunks = Math.ceil(data.byteLength / this.chunkSize);
      const transferId = this.generateTransferId();
      
      // 发送传输开始信号
      this.sendMessage({
        type: 'TRANSFER_START',
        payload: {
          transferId,
          totalSize: data.byteLength,
          totalChunks,
          chunkSize: this.chunkSize
        }
      });

      // 分块传输
      for (let chunkIndex = 0; chunkIndex < totalChunks; chunkIndex++) {
        const start = chunkIndex * this.chunkSize;
        const end = Math.min(start + this.chunkSize, data.byteLength);
        const chunk = data.slice(start, end);
        
        const success = await this.sendChunk(transferId, chunkIndex, chunk);
        if (!success) {
          throw new Error(`块 ${chunkIndex} 传输失败`);
        }

        // 更新进度
        if (onProgress) {
          onProgress((chunkIndex + 1) / totalChunks * 100);
        }
      }

      // 发送传输完成信号
      this.sendMessage({
        type: 'TRANSFER_COMPLETE',
        payload: { transferId }
      });

      return true;
    } catch (error) {
      console.error('分块传输失败:', error);
      return false;
    }
  }

  // 发送单个块
  private async sendChunk(transferId: string, chunkIndex: number, chunk: ArrayBuffer): Promise<boolean> {
    return new Promise((resolve, reject) => {
      const timeoutId = setTimeout(() => {
        reject(new Error(`块 ${chunkIndex} 传输超时`));
      }, this.timeout);

      // 监听确认消息
      const messageHandler = (event: MessageEvent) => {
        if (event.data.type === 'CHUNK_CONFIRMED' && 
            event.data.payload.transferId === transferId &&
            event.data.payload.chunkIndex === chunkIndex) {
          clearTimeout(timeoutId);
          window.removeEventListener('message', messageHandler);
          resolve(true);
        }
      };

      window.addEventListener('message', messageHandler);

      // 发送块数据
      this.sendMessage({
        type: 'CHUNK_DATA',
        payload: {
          transferId,
          chunkIndex,
          data: Array.from(new Uint8Array(chunk))
        }
      });
    });
  }

  // 生成传输ID
  private generateTransferId(): string {
    return `transfer_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
  }

  // 发送消息
  private sendMessage(message: any): void {
    window.postMessage(message, this.targetOrigin);
  }
}
```

### 2. 流式传输方案

```typescript
// apps/web/src/lib/postmessage-streaming-transfer.ts
export class StreamingPostMessageTransfer {
  private chunkSize: number;
  private targetOrigin: string;
  private buffer: Uint8Array[] = [];
  private isStreaming = false;

  constructor(chunkSize = 1024 * 1024, targetOrigin = '*') {
    this.chunkSize = chunkSize; // 1MB 每块
    this.targetOrigin = targetOrigin;
  }

  // 流式传输
  async streamData(data: ArrayBuffer, onProgress?: (progress: number) => void): Promise<boolean> {
    try {
      this.isStreaming = true;
      const streamId = this.generateStreamId();
      let transferredBytes = 0;

      // 发送流开始信号
      this.sendMessage({
        type: 'STREAM_START',
        payload: {
          streamId,
          totalSize: data.byteLength
        }
      });

      // 流式传输
      for (let offset = 0; offset < data.byteLength; offset += this.chunkSize) {
        if (!this.isStreaming) break;

        const chunk = data.slice(offset, Math.min(offset + this.chunkSize, data.byteLength));
        const chunkData = Array.from(new Uint8Array(chunk));
        
        this.sendMessage({
          type: 'STREAM_CHUNK',
          payload: {
            streamId,
            offset,
            data: chunkData,
            isLastChunk: offset + this.chunkSize >= data.byteLength
          }
        });

        transferredBytes += chunk.byteLength;
        if (onProgress) {
          onProgress(transferredBytes / data.byteLength * 100);
        }

        // 添加小延迟避免阻塞
        await new Promise(resolve => setTimeout(resolve, 10));
      }

      // 发送流结束信号
      this.sendMessage({
        type: 'STREAM_END',
        payload: { streamId }
      });

      return true;
    } catch (error) {
      console.error('流式传输失败:', error);
      return false;
    } finally {
      this.isStreaming = false;
    }
  }

  // 停止流式传输
  stopStreaming(): void {
    this.isStreaming = false;
  }

  private generateStreamId(): string {
    return `stream_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
  }

  private sendMessage(message: any): void {
    window.postMessage(message, this.targetOrigin);
  }
}
```

### 3. 压缩传输方案

```typescript
// apps/web/src/lib/postmessage-compressed-transfer.ts
export class CompressedPostMessageTransfer {
  private targetOrigin: string;

  constructor(targetOrigin = '*') {
    this.targetOrigin = targetOrigin;
  }

  // 压缩传输
  async transferWithCompression(data: ArrayBuffer, compressionLevel = 6): Promise<boolean> {
    try {
      // 检查数据大小
      if (data.byteLength < 1024 * 1024) { // < 1MB
        // 小数据直接传输
        return this.transferDirect(data);
      }

      // 压缩数据
      const compressedData = await this.compressData(data, compressionLevel);
      const compressionRatio = compressedData.byteLength / data.byteLength;

      console.log(`压缩率: ${(compressionRatio * 100).toFixed(2)}%`);

      // 如果压缩效果不好，使用分块传输
      if (compressionRatio > 0.8) {
        console.log('压缩效果不佳，使用分块传输');
        const chunkedTransfer = new ChunkedPostMessageTransfer();
        return await chunkedTransfer.transferLargeData(data);
      }

      // 传输压缩数据
      this.sendMessage({
        type: 'COMPRESSED_DATA',
        payload: {
          originalSize: data.byteLength,
          compressedSize: compressedData.byteLength,
          compressionRatio,
          data: Array.from(new Uint8Array(compressedData))
        }
      });

      return true;
    } catch (error) {
      console.error('压缩传输失败:', error);
      return false;
    }
  }

  // 压缩数据
  private async compressData(data: ArrayBuffer, level: number): Promise<ArrayBuffer> {
    // 使用 Web Workers 进行压缩
    return new Promise((resolve, reject) => {
      const worker = new Worker('/workers/compression-worker.js');
      
      worker.onmessage = (event) => {
        if (event.data.type === 'COMPRESSED') {
          resolve(event.data.compressedData);
        } else if (event.data.type === 'ERROR') {
          reject(new Error(event.data.error));
        }
        worker.terminate();
      };

      worker.postMessage({
        type: 'COMPRESS',
        data: data,
        level: level
      });
    });
  }

  // 直接传输
  private async transferDirect(data: ArrayBuffer): Promise<boolean> {
    this.sendMessage({
      type: 'DIRECT_DATA',
      payload: {
        data: Array.from(new Uint8Array(data))
      }
    });
    return true;
  }

  private sendMessage(message: any): void {
    window.postMessage(message, this.targetOrigin);
  }
}
```

### 4. 智能传输策略

```typescript
// apps/web/src/lib/postmessage-smart-transfer.ts
export class SmartPostMessageTransfer {
  private strategies = {
    DIRECT: 'direct',
    CHUNKED: 'chunked',
    STREAMING: 'streaming',
    COMPRESSED: 'compressed'
  };

  // 智能选择传输策略
  async smartTransfer(data: ArrayBuffer, onProgress?: (progress: number) => void): Promise<boolean> {
    const strategy = this.selectStrategy(data.byteLength);
    console.log(`选择传输策略: ${strategy}`);

    switch (strategy) {
      case this.strategies.DIRECT:
        return this.directTransfer(data);
      
      case this.strategies.CHUNKED:
        const chunkedTransfer = new ChunkedPostMessageTransfer();
        return await chunkedTransfer.transferLargeData(data, onProgress);
      
      case this.strategies.STREAMING:
        const streamingTransfer = new StreamingPostMessageTransfer();
        return await streamingTransfer.streamData(data, onProgress);
      
      case this.strategies.COMPRESSED:
        const compressedTransfer = new CompressedPostMessageTransfer();
        return await compressedTransfer.transferWithCompression(data);
      
      default:
        throw new Error(`未知的传输策略: ${strategy}`);
    }
  }

  // 选择传输策略
  private selectStrategy(dataSize: number): string {
    const sizeInMB = dataSize / (1024 * 1024);
    
    if (sizeInMB < 5) {
      return this.strategies.DIRECT;
    } else if (sizeInMB < 25) {
      return this.strategies.CHUNKED;
    } else if (sizeInMB < 100) {
      return this.strategies.STREAMING;
    } else {
      return this.strategies.COMPRESSED;
    }
  }

  // 直接传输
  private async directTransfer(data: ArrayBuffer): Promise<boolean> {
    try {
      window.postMessage({
        type: 'DIRECT_DATA',
        payload: {
          data: Array.from(new Uint8Array(data))
        }
      }, '*');
      return true;
    } catch (error) {
      console.error('直接传输失败:', error);
      return false;
    }
  }
}
```

### 1. 传输大小策略

```typescript
// 推荐的传输大小策略
const TRANSFER_STRATEGY = {
  // 小文件：直接传输
  SMALL: 5 * 1024 * 1024,      // < 5MB
  
  // 中等文件：分块传输
  MEDIUM: 25 * 1024 * 1024,    // 5-25MB
  
  // 大文件：流式传输
  LARGE: 100 * 1024 * 1024,    // 25-100MB
  
  // 超大文件：压缩传输
  HUGE: 500 * 1024 * 1024      // > 100MB
};

export function getOptimalChunkSize(dataSize: number): number {
  if (dataSize < TRANSFER_STRATEGY.SMALL) {
    return dataSize; // 直接传输
  } else if (dataSize < TRANSFER_STRATEGY.MEDIUM) {
    return 5 * 1024 * 1024; // 5MB 块
  } else if (dataSize < TRANSFER_STRATEGY.LARGE) {
    return 1024 * 1024; // 1MB 块
  } else {
    return 512 * 1024; // 512KB 块
  }
}
```

### 2. 错误处理和重试

```typescript
// 重试机制
export async function transferWithRetry(
  transferFn: () => Promise<boolean>,
  maxRetries: number = 3,
  baseDelay: number = 1000
): Promise<boolean> {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const result = await transferFn();
      if (result) return true;
    } catch (error) {
      console.warn(`传输尝试 ${attempt} 失败:`, error);
      
      if (attempt === maxRetries) {
        throw new Error(`传输失败，已重试 ${maxRetries} 次`);
      }
      
      // 指数退避
      const delay = baseDelay * Math.pow(2, attempt - 1);
      await new Promise(resolve => setTimeout(resolve, delay));
    }
  }
  return false;
}
```

### 3. 内存监控

```typescript
// 内存监控
export class MemoryMonitor {
  private maxMemoryUsage: number = 100 * 1024 * 1024; // 100MB
  private checkInterval: number = 1000; // 1秒
  private intervalId: NodeJS.Timeout | null = null;

  startMonitoring(): void {
    this.intervalId = setInterval(() => {
      this.checkMemoryUsage();
    }, this.checkInterval);
  }

  stopMonitoring(): void {
    if (this.intervalId) {
      clearInterval(this.intervalId);
      this.intervalId = null;
    }
  }

  private checkMemoryUsage(): void {
    if (performance.memory) {
      const usedMemory = performance.memory.usedJSHeapSize;
      const maxMemory = performance.memory.jsHeapSizeLimit;
      
      const usagePercentage = (usedMemory / maxMemory) * 100;
      
      if (usagePercentage > 80) {
        console.warn(`内存使用率过高: ${usagePercentage.toFixed(2)}%`);
        // 可以触发垃圾回收或暂停传输
        if (global.gc) {
          global.gc();
        }
      }
    }
  }

  setMaxMemoryUsage(bytes: number): void {
    this.maxMemoryUsage = bytes;
  }
}
```

### 4. 性能优化

```typescript
// 性能优化工具
export class PerformanceOptimizer {
  // 批量处理
  static async batchProcess<T>(
    items: T[],
    batchSize: number,
    processor: (batch: T[]) => Promise<void>
  ): Promise<void> {
    for (let i = 0; i < items.length; i += batchSize) {
      const batch = items.slice(i, i + batchSize);
      await processor(batch);
      
      // 让出控制权，避免阻塞
      await new Promise(resolve => setTimeout(resolve, 0));
    }
  }

  // 内存清理
  static cleanupMemory(): void {
    // 清理全局变量
    if (global.gc) {
      global.gc();
    }
    
    // 清理定时器
    const highestTimeoutId = setTimeout(() => {}, 0);
    for (let i = 0; i < highestTimeoutId; i++) {
      clearTimeout(i);
    }
    
    // 清理间隔器
    const highestIntervalId = setInterval(() => {}, 0);
    for (let i = 0; i < highestIntervalId; i++) {
      clearInterval(i);
    }
  }

  // 节流函数
  static throttle<T extends (...args: any[]) => any>(
    func: T,
    delay: number
  ): (...args: Parameters<T>) => void {
    let timeoutId: NodeJS.Timeout | null = null;
    let lastExecTime = 0;
    
    return (...args: Parameters<T>) => {
      const currentTime = Date.now();
      
      if (currentTime - lastExecTime > delay) {
        func(...args);
        lastExecTime = currentTime;
      } else {
        if (timeoutId) clearTimeout(timeoutId);
        timeoutId = setTimeout(() => {
          func(...args);
          lastExecTime = Date.now();
        }, delay - (currentTime - lastExecTime));
      }
    };
  }
}
```

## 总结

### 关键要点：

1. **理论限制**：2GB（大多数浏览器）
2. **实际安全限制**：10MB
3. **推荐限制**：5MB
4. **最大可用限制**：50MB

### 解决方案优先级：

1. **小数据（< 5MB）**：直接传输
2. **中等数据（5-25MB）**：分块传输
3. **大数据（25-100MB）**：流式传输
4. **超大数据（> 100MB）**：压缩+分块

### 最佳实践：

- 始终实现分块传输机制
- 添加进度显示和错误处理
- 实现重试机制
- 考虑数据压缩
- 监控内存使用情况
- 使用智能传输策略

通过这些方案，可以确保在各种数据大小下都能稳定可靠地使用 postMessage 传输数据。
