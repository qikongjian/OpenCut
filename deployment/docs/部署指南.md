# SmartCut Frontend 完整部署指南

## 📋 部署概览

本指南提供了 SmartCut Frontend 项目的完整部署方案，包括自动化部署脚本和详细的手动部署步骤。

## 🎯 部署架构

- **服务器**: 39.105.24.90
- **用户**: mf
- **端口**: 80 (HTTP), 443 (HTTPS可选)
- **容器化**: Docker Compose + Nginx 反向代理
- **数据库**: PostgreSQL 15
- **缓存**: Redis 7
- **应用**: Next.js 15 + Node.js

## 📁 部署文件清单

### 核心部署文件
- `deploy-tar.sh` - 主部署脚本（推荐使用）
- `check-server-env.sh` - 服务器环境检查脚本
- `init-database.sh` - 数据库初始化脚本
- `test-deployment.sh` - 部署验证脚本
- `.env.production` - 生产环境配置
- `docker-compose.prod.yml` - Docker Compose 配置
- `nginx.conf` - Nginx 反向代理配置
- `redis.conf` - Redis 缓存配置

### 应用文件
- `apps/web/Dockerfile` - 应用容器配置
- `packages/db/` - 数据库包（Drizzle ORM）
- `packages/auth/` - 认证包（Better Auth）

## 🚀 一键部署（推荐）

### 1. 环境检查

首先检查服务器环境是否满足要求：

```bash
chmod +x check-server-env.sh
./check-server-env.sh
```

### 2. 配置环境变量

编辑 `.env.production` 文件，修改关键配置：

```bash
# 认证配置（必须修改）
BETTER_AUTH_SECRET="your-secure-secret-key-here"
NEXT_PUBLIC_BETTER_AUTH_URL="http://39.105.24.90"

# 数据库配置（已配置为Docker容器）
DATABASE_URL="postgresql://opencut:opencutthegoat@postgres:5432/opencut"

# Redis配置（已配置为Docker容器）
UPSTASH_REDIS_REST_URL="http://redis:6379"
UPSTASH_REDIS_REST_TOKEN="production-redis-token"

# 可选API配置
FREESOUND_CLIENT_ID=""  # 音效搜索
FREESOUND_API_KEY=""
CLOUDFLARE_ACCOUNT_ID=""  # 文件存储
R2_ACCESS_KEY_ID=""
R2_SECRET_ACCESS_KEY=""
MODAL_TRANSCRIPTION_URL=""  # AI转录
```

### 3. 执行部署

运行主部署脚本：

```bash
chmod +x deploy-tar.sh
./deploy-tar.sh
```

### 4. 验证部署

运行测试脚本验证部署结果：

```bash
chmod +x test-deployment.sh
./test-deployment.sh
```

## 📋 手动部署步骤

### 1. 服务器环境准备

```bash
# 连接服务器
ssh mf@39.105.24.90

# 更新系统
sudo apt-get update && sudo apt-get upgrade -y

# 安装Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# 安装Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 安装其他工具
sudo apt-get install -y git curl wget unzip
```

### 2. 项目部署

```bash
# 创建项目目录
mkdir -p /home/mf/opencut
cd /home/mf/opencut

# 上传项目文件（通过部署脚本自动完成）
# 或手动上传所有必要文件

# 构建应用镜像
docker build -t opencut-app:latest -f apps/web/Dockerfile .

# 启动所有服务
docker-compose -f docker-compose.prod.yml up -d

# 初始化数据库
chmod +x init-database.sh
./init-database.sh
```

## 🐳 Docker 服务说明

### 服务组件

1. **opencut-app**: 主应用容器（Next.js）
2. **postgres**: PostgreSQL 数据库
3. **redis**: Redis 缓存
4. **nginx**: Nginx 反向代理
5. **db-backup**: 自动数据库备份

### 服务管理命令

```bash
# 查看服务状态
docker-compose -f docker-compose.prod.yml ps

# 查看日志
docker-compose -f docker-compose.prod.yml logs [service-name]

# 重启服务
docker-compose -f docker-compose.prod.yml restart [service-name]

# 停止所有服务
docker-compose -f docker-compose.prod.yml down

# 启动所有服务
docker-compose -f docker-compose.prod.yml up -d
```

## 🔧 故障排除

### 常见问题

1. **Docker权限问题**
   ```bash
   sudo usermod -aG docker $USER
   # 重新登录生效
   ```

2. **端口占用**
   ```bash
   sudo netstat -tulpn | grep :80
   sudo fuser -k 80/tcp
   ```

3. **数据库连接失败**
   ```bash
   docker logs opencut-postgres
   docker exec -it opencut-postgres psql -U opencut -d opencut
   ```

4. **应用启动失败**
   ```bash
   docker logs opencut-container
   docker-compose -f docker-compose.prod.yml logs opencut-app
   ```

### 日志查看

```bash
# 实时查看应用日志
docker-compose -f docker-compose.prod.yml logs -f opencut-app

# 查看数据库日志
docker-compose -f docker-compose.prod.yml logs postgres

# 查看Nginx日志
docker-compose -f docker-compose.prod.yml logs nginx
```

## 🔒 安全配置

### 1. 防火墙设置

```bash
sudo ufw enable
sudo ufw allow 22    # SSH
sudo ufw allow 80    # HTTP
sudo ufw allow 443   # HTTPS
```

### 2. SSL证书配置（可选）

```bash
# 安装Certbot
sudo apt-get install certbot python3-certbot-nginx

# 获取SSL证书
sudo certbot --nginx -d your-domain.com

# 自动续期
echo "0 12 * * * /usr/bin/certbot renew --quiet" | sudo crontab -
```

### 3. 安全加固

```bash
# 修改SSH端口（可选）
sudo nano /etc/ssh/sshd_config
# Port 2222

# 禁用root登录
# PermitRootLogin no

# 重启SSH服务
sudo systemctl restart ssh
```

## 🆘 紧急恢复

### 快速回滚

```bash
# 停止当前服务
docker-compose -f docker-compose.prod.yml down

# 恢复到上一个版本
git checkout previous-version
docker build -t opencut-app:latest -f apps/web/Dockerfile .
docker-compose -f docker-compose.prod.yml up -d
```

### 数据恢复

```bash
# 恢复数据库
docker exec -i opencut-postgres psql -U opencut -d opencut < latest_backup.sql

# 恢复应用数据
docker run --rm -v opencut-uploads:/data -v $(pwd):/backup alpine tar xzf /backup/uploads_backup.tar.gz -C /data
```
