# OpenCut 项目部署说明

## 📋 部署概览

本文档提供了 OpenCut 项目的完整部署方案，包括自动化部署脚本和手动部署步骤。

## 🎯 部署目标

- **服务器**: 39.105.24.90
- **用户**: mf
- **端口**: 80 (HTTP)
- **容器**: Docker Compose + Nginx 反向代理

## 📁 部署文件说明

### 核心部署文件

- `deploy-tar.sh` - 主部署脚本（推荐）
- `check-server-env.sh` - 服务器环境检查脚本
- `init-database.sh` - 数据库初始化脚本
- `test-deployment.sh` - 部署测试脚本
- `.env.production` - 生产环境配置
- `docker-compose.prod.yml` - Docker Compose 配置
- `nginx.conf` - Nginx 配置
- `redis.conf` - Redis 配置

### 支持文件

- `apps/web/Dockerfile` - 应用容器配置
- `packages/db/` - 数据库包
- `packages/auth/` - 认证包

## 🚀 快速部署（推荐）

### 1. 准备工作

确保本地已安装：

- Git
- Bun 或 Node.js
- SSH 客户端
- curl（用于测试）

### 2. 环境检查

首先检查服务器环境：

```bash
chmod +x check-server-env.sh
./check-server-env.sh
```

### 3. 配置环境变量

编辑 `.env.production` 文件，修改必要的配置：

```bash
# 数据库配置（已配置为使用Docker容器）
DATABASE_URL="postgresql://opencut:opencutthegoat@postgres:5432/opencut"

# 认证配置（生产环境需要修改密钥）
BETTER_AUTH_SECRET="opencut-production-secret-key-change-this-in-production"
NEXT_PUBLIC_BETTER_AUTH_URL="http://39.105.24.90"

# Redis 配置
UPSTASH_REDIS_REST_URL="https://your-redis-url.upstash.io"
UPSTASH_REDIS_REST_TOKEN="your-redis-token"

# 其他 API 配置...
```

### 3. 执行一键部署

```bash
chmod +x quick-deploy.sh
./quick-deploy.sh
```

脚本会自动：

1. 检查必要文件
2. 测试服务器连接
3. 初始化服务器环境（首次部署）
4. 构建并部署应用
5. 验证部署状态

## 🐳 Docker 部署方案

### 使用 Docker Compose（推荐）

```bash
# 在服务器上
cd /home/mf/opencut
docker-compose -f docker-compose.prod.yml up -d
```

### 单独 Docker 容器

```bash
# 构建镜像
docker build -t opencut-app:latest -f apps/web/Dockerfile .

# 运行容器
docker run -d \
  --name opencut-container \
  --restart unless-stopped \
  -p 3000:3000 \
  --env-file .env.production \
  opencut-app:latest
```

## 🔍 故障排除

### 常见问题

1. **应用无法访问**

   ```bash
   # 检查容器状态
   docker ps
   # 检查日志
   docker logs opencut-container
   ```

2. **数据库连接失败**

   - 检查 `.env` 中的数据库配置
   - 确保 PostgreSQL 服务运行正常

3. **文件上传失败**
   - 检查 Nginx 配置中的 `client_max_body_size`
   - 确保磁盘空间充足

### 日志位置

- 应用日志：`docker logs opencut-container`
- Nginx 日志：`/var/log/nginx/`
- 系统日志：`/var/log/syslog`
