# 转场视频质量优化测试

## 问题描述
用户反馈转场视频导出后质量很差，出现大量噪点和模糊：
- 视频画面有明显的噪点和颗粒感
- 图像模糊不清晰
- 整体视觉质量远低于原始视频

## 问题分析

### 原有质量问题
1. **硬编码的低质量设置**：
   - 使用固定的 `preset: 'fast'` 和 `crf: '23'`
   - 没有根据用户的导出质量配置调整参数
   - 转场处理时质量损失较大

2. **未优化的编码参数**：
   - 缺少适当的像素格式和配置文件设置
   - 没有使用最优的H.264编码参数

## 优化方案

### 1. 动态质量设置
根据 `exportConfig.quality` 动态选择编码参数：

```typescript
const getQualitySettings = (quality: string) => {
  switch (quality) {
    case 'high':
      return {
        preset: 'slow',      // 最佳质量预设
        crf: '16',           // 非常高质量 (16是近无损)
        profile: 'high',     // H.264高配置文件
        level: '4.1'         // 支持高分辨率
      };
    case 'medium':
      return {
        preset: 'medium',    // 平衡质量和速度
        crf: '20',           // 中等质量
        profile: 'main',     // 主配置文件
        level: '4.0'
      };
    case 'low':
      return {
        preset: 'fast',      // 快速编码
        crf: '26',           // 较低质量但速度快
        profile: 'baseline', // 基础配置文件
        level: '3.1'
      };
  }
};
```

### 2. 完整的FFmpeg质量参数
```bash
-c:v libx264
-preset slow              # 根据质量设置动态调整
-crf 16                   # 根据质量设置动态调整
-pix_fmt yuv420p          # 确保兼容性
-profile:v high           # 根据质量设置动态调整
-level 4.1                # 根据质量设置动态调整
-movflags +faststart      # 优化流媒体播放
```

### 3. 质量等级说明

#### High Quality (高质量)
- **CRF 16**: 近无损质量，文件较大但画质极佳
- **Preset slow**: 最佳压缩效率，编码时间较长
- **Profile high**: 支持所有H.264高级特性
- **适用场景**: 最终成品、高质量要求的项目

#### Medium Quality (中等质量) 
- **CRF 20**: 优秀质量，文件大小适中
- **Preset medium**: 平衡质量和速度
- **Profile main**: 主流兼容性
- **适用场景**: 大多数常规用途

#### Low Quality (低质量)
- **CRF 26**: 可接受质量，文件较小
- **Preset fast**: 快速编码
- **Profile baseline**: 最大兼容性
- **适用场景**: 预览、快速分享

## 技术改进

### 1. 保持原始质量的处理
- 基础片段处理使用 `-c copy` 流复制
- 避免不必要的重编码
- 只在转场处理时进行质量编码

### 2. 智能质量选择
- 根据用户在导出对话框中选择的质量等级
- 自动应用相应的编码参数
- 在控制台输出当前使用的质量设置

### 3. 兼容性优化
- 使用 `yuv420p` 像素格式确保广泛兼容性
- 添加 `+faststart` 标志优化网络播放
- 合适的H.264 Level设置

## 预期改进效果

### 视觉质量改进
- ✅ **消除噪点**: 使用更低的CRF值减少压缩噪点
- ✅ **提高清晰度**: 优化的预设和配置文件
- ✅ **保持细节**: 更好的编码参数保留更多图像细节
- ✅ **色彩准确性**: 正确的像素格式和色彩空间

### 用户体验改进
- ✅ **质量可控**: 用户可以选择适合的质量等级
- ✅ **透明度**: 在控制台显示当前使用的质量设置
- ✅ **兼容性**: 确保在各种播放器和平台上正常播放

## 测试场景

### 场景1: 高质量导出测试
- **操作**: 选择"高质量"导出设置，添加转场效果
- **预期**: CRF=16, preset=slow, 画质接近原始视频
- **验证**: 检查导出视频的清晰度和细节保持

### 场景2: 中等质量导出测试  
- **操作**: 选择"中等质量"导出设置，添加转场效果
- **预期**: CRF=20, preset=medium, 质量和文件大小平衡
- **验证**: 确认质量可接受且文件大小合理

### 场景3: 低质量快速导出测试
- **操作**: 选择"低质量"导出设置，添加转场效果
- **预期**: CRF=26, preset=fast, 快速完成但质量降低
- **验证**: 确认导出速度快且质量仍可接受

### 场景4: 质量对比测试
- **操作**: 同一视频使用不同质量设置导出
- **预期**: 能明显看出质量差异
- **验证**: 高质量 > 中等质量 > 低质量

## 性能影响

### 编码时间变化
- **高质量**: 编码时间增加约50-100%，但质量显著提升
- **中等质量**: 编码时间适中，质量明显改善
- **低质量**: 编码时间最短，质量有所改善

### 文件大小变化
- **高质量**: 文件大小可能增加30-50%
- **中等质量**: 文件大小适中增加
- **低质量**: 文件大小控制在较小范围
