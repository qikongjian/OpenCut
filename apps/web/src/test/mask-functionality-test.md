# 蒙板功能测试文档

## 测试概述

本文档包含OpenCut编辑器第一阶段蒙板功能的全面测试用例，验证基础形状蒙板（圆形、矩形）的正确性和稳定性。

## 测试环境

- **浏览器**: Chrome 120+, Firefox 120+, Safari 17+
- **设备**: 桌面端、平板端
- **分辨率**: 1920x1080, 1366x768, 2560x1440
- **操作系统**: Windows 11, macOS 14, Ubuntu 22.04

## 功能测试用例

### 1. 蒙板创建测试

#### 1.1 从Effects面板添加蒙板
**测试步骤**:
1. 打开OpenCut编辑器
2. 导入一个视频文件到时间轴
3. 选择时间轴上的视频元素
4. 点击左侧媒体面板的"Effects"标签
5. 点击矩形蒙板模板
6. 验证蒙板是否成功添加

**预期结果**:
- ✅ Effects面板显示蒙板模板
- ✅ 点击后显示成功添加提示
- ✅ 右侧属性面板显示蒙板设置
- ✅ 预览面板显示蒙板效果

#### 1.2 从属性面板添加蒙板
**测试步骤**:
1. 选择时间轴上的元素
2. 在右侧属性面板找到"蒙板设置"区域
3. 点击矩形或圆形按钮添加蒙板
4. 验证蒙板添加结果

**预期结果**:
- ✅ 属性面板显示蒙板设置区域
- ✅ 添加按钮响应正常
- ✅ 蒙板成功添加到元素
