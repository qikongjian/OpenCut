# 🎭 OpenCut 蒙版操作完整指南

## 📋 蒙版放大缩小操作方法

### 🖱️ **方式一：拖拽控制点缩放（推荐）**

#### 控制点说明
当选中蒙版时，会显示以下控制点：

```
    🔲 ←─────────→ 🔲
    │             │
    │      ⭕      │  ← 中心点（移动）
    │             │
    🔲 ←─────────→ 🔲
           ↑
        🔄 旋转点
```

#### 四个角控制点 🔲
- **左上角 (nw-resize)**：向左上方向缩放
- **右上角 (ne-resize)**：向右上方向缩放  
- **右下角 (se-resize)**：向右下方向缩放
- **左下角 (sw-resize)**：向左下方向缩放

#### 操作步骤
```
1. 🎯 点击选中蒙版（边框变蓝色）
2. 🖱️ 将鼠标悬停在四个角的控制点上
3. ↔️ 鼠标指针变成对应的缩放箭头
4. 🖱️ 按住鼠标左键拖拽进行缩放
5. ✅ 松开鼠标完成缩放
```

#### 🔧 高级缩放技巧
- **等比例缩放**：按住 `Shift` 键 + 拖拽角控制点
- **从中心缩放**：按住 `Alt` 键 + 拖拽（功能待实现）
- **快速重置**：双击蒙版重置到默认大小

### 📊 **方式二：属性面板精确调整**

#### 尺寸控制
在右侧属性面板中：

```
┌─ 尺寸 ─────────────┐
│ 宽度: [___] %      │  ← 1-200%
│ 高度: [___] %      │  ← 1-200%
└────────────────────┘
```

- **宽度输入框**：数值范围 1-200（百分比）
- **高度输入框**：数值范围 1-200（百分比）
- **实时预览**：输入时立即更新蒙版大小

#### 位置控制
```
┌─ 位置 ─────────────┐
│ X: [___] %         │  ← -100 到 100%
│ Y: [___] %         │  ← -100 到 100%
└────────────────────┘
```

#### 其他属性
```
┌─ 旋转 ─────────────┐
│ ●────○────● 45°    │  ← -180° 到 180°
└────────────────────┘

┌─ 透明度 ───────────┐
│ ●──────○── 80%     │  ← 0% 到 100%
└────────────────────┘
```

#### 2. 快速操作
- **选中蒙版**：单击蒙版边框
- **移动蒙版**：拖拽中心点 ⭕
- **重置大小**：双击蒙版
- **删除蒙版**：选中后按 `Delete` 键

#### 3. 键盘快捷键
- `Shift + 拖拽`：等比例缩放
- `Ctrl + Z`：撤销操作
- `Ctrl + Y`：重做操作
- `Delete`：删除选中蒙版

### 📐 **尺寸和边界限制**

#### 尺寸限制
- **最小尺寸**：1% × 1%（防止蒙版过小不可见）
- **最大尺寸**：200% × 200%（允许超出画布）
- **精度**：支持1%的精度调整

#### 坐标范围
- **X坐标**：-100% 到 100%（相对于画布中心）
- **Y坐标**：-100% 到 100%（相对于画布中心）
- **坐标系**：中心点 (0,0) 为画布中心

#### 边界行为
```
画布边界：
┌─────────────────┐
│  (-1,1)   (1,1) │
│     ┌─────┐     │
│     │蒙版 │     │  ← 蒙版可以部分超出边界
│     └─────┘     │
│ (-1,-1)  (1,-1) │
└─────────────────┘
```

### 🔧 **故障排除**

#### 常见问题
1. **控制点不显示**
   - 确保蒙版已选中
   - 检查是否在编辑模式

2. **缩放不生效**
   - 检查是否达到尺寸限制
   - 确保鼠标在控制点上

3. **蒙版位置偏移**
   - 刷新页面重新加载
   - 检查坐标系统设置
