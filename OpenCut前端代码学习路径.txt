🎯 OpenCut前端代码学习路径指南
=====================================

📋 学习目标
-----------
从零开始理解OpenCut前端项目的完整架构，掌握视频编辑器的核心实现原理，
包括状态管理、组件设计、交互逻辑、媒体处理等关键技术。

📚 第一阶段：项目基础架构 (1-2天)
================================

1.1 项目入口和布局
------------------
学习顺序：
1. apps/web/src/app/layout.tsx - 根布局，了解全局配置
2. apps/web/src/app/page.tsx - 首页，了解路由结构  
3. apps/web/src/app/editor/[project_id]/page.tsx - 编辑器主页面

学习重点：
✓ Next.js App Router 的使用
✓ 全局Provider的配置（ThemeProvider, StorageProvider等）
✓ 编辑器页面的面板布局结构
✓ 响应式设计和可调整面板

关键概念：
- Next.js 15 App Router架构
- 全局状态提供者模式
- ResizablePanelGroup布局系统

1.2 核心状态管理
----------------
学习顺序：
1. apps/web/src/stores/editor-store.ts - 编辑器基础状态
2. apps/web/src/stores/project-store.ts - 项目管理
3. apps/web/src/stores/media-store.ts - 媒体文件管理
4. apps/web/src/stores/timeline-store.ts - 时间线核心逻辑
5. apps/web/src/stores/playback-store.ts - 播放控制

学习重点：
✓ Zustand状态管理模式
✓ 各个Store之间的依赖关系
✓ 状态更新的流程
✓ 异步操作处理

关键概念：
- Zustand状态管理库
- Store间通信机制
- 状态持久化策略

🔧 阅读技巧和建议
==================

1. 调试工具使用
---------------
在浏览器控制台中访问调试信息：
```javascript
// 开发环境下可用的调试工具
window.__OPENCUT_DEBUG__ = {
  stores: {
    timeline: useTimelineStore.getState,
    media: useMediaStore.getState,
    editor: useEditorStore.getState,
  },
  actions: {
    invoke: invokeAction,
  },
};
```

2. 关键概念理解顺序
-------------------
1. 状态管理 → 理解数据流
2. 组件结构 → 理解UI架构  
3. 交互逻辑 → 理解用户操作
4. 工具函数 → 理解辅助功能

3. 重点关注的文件
-----------------
- timeline-store.ts - 最复杂的业务逻辑
- preview-panel.tsx - 最复杂的渲染逻辑
- ffmpeg-utils.ts - 核心视频处理
- storage-service.ts - 数据持久化

4. 实践建议
-----------
✓ 边读边运行 - 启动开发服务器，实时查看效果
✓ 使用断点 - 在关键函数处设置断点调试
✓ 画流程图 - 画出数据流和组件关系图
✓ 做笔记 - 记录重要的设计模式和实现细节
✓ 修改代码 - 尝试修改一些参数，观察效果变化
