# 共享规则与标准

## 通用协作规则

### R1: 需求理解标准
- 必须完整阅读相关文档：需求文档、设计稿、技术规范
- 识别功能边界：明确什么要做，什么不做
- 确认验收标准：可测试、可验证的成功指标
- 风险评估：技术难度、时间成本、资源依赖

### R2: 输出文档标准
- 结构化内容：使用标准模板和章节组织
- 可执行性：提供具体的操作步骤和检查清单
- 可追溯性：包含决策依据和参考资料
- 版本管理：记录变更历史和更新原因

### R3: 质量保证标准
- 自检机制：完成后进行功能性和完整性检查
- 同行评审：关键输出需要团队成员评审
- 用户验证：面向最终用户的可用性验证
- 持续改进：收集反馈并迭代优化

## OpenCut项目技术栈

### T1: 核心技术栈
- **前端框架**: Next.js 14+ + React 18+ + TypeScript
- **UI组件库**: Radix UI + Tailwind CSS
- **状态管理**: Zustand + React Context
- **数据库**: PostgreSQL + Drizzle ORM
- **认证系统**: Better Auth
- **部署平台**: Vercel + Docker

### T2: 视频处理技术
- **视频处理**: FFmpeg.js + WebCodecs API
- **渲染引擎**: Canvas 2D + WebGL
- **音频处理**: Web Audio API
- **文件存储**: IndexedDB + OPFS (Origin Private File System)

### T3: 性能要求
- **加载性能**: 首屏 < 3s，交互响应 < 100ms
- **处理能力**: 支持 >1GB 大文件处理
- **内存管理**: 避免内存泄漏，合理垃圾回收
- **兼容性**: Chrome 90+, Firefox 88+, Safari 14+

## 视频编辑领域知识

### V1: 核心工作流
1. **媒体导入**: 支持主流视频/音频格式
2. **时间轴编辑**: 精确到帧的剪切、拼接
3. **效果处理**: 转场、滤镜、调色、音效
4. **预览渲染**: 实时预览 + 高质量导出

### V2: 竞品参考标准
- **剪映**: 智能功能 + 简单易用
- **CapCut**: 专业功能 + 移动优先
- **Premiere**: 专业级 + 功能完整
- **DaVinci**: 调色专业 + 性能优化

### V3: 用户体验原则
- **学习成本**: 新用户 < 5分钟上手基础功能
- **操作效率**: 熟练用户快捷键覆盖 >80% 操作
- **错误恢复**: 撤销/重做 + 自动保存机制
- **反馈及时**: 所有操作 < 200ms 视觉反馈
