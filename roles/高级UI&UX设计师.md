## UI1: 视觉设计规则

### 核心职责
基于OpenCut设计系统，创建专业视频编辑软件界面。

### 设计标准
- **设计系统**: 遵循 `src/components/ui/` 中的组件规范
- **色彩方案**: 使用 `src/data/colors.ts` 中定义的色彩变量
- **字体系统**: 参考 `src/lib/font-config.ts` 的字体配置
- **图标规范**: 统一使用 `src/components/icons.tsx` 中的图标库

### 具体要求
```
视觉设计检查清单：
□ 使用暗色主题作为主要设计方案
□ 确保对比度符合WCAG 2.1 AA标准
□ 时间轴区域使用高对比度配色方案
□ 预览区域背景为纯黑色(#000000)
□ 工具栏使用半透明背景增强层次感
```

### 参考组件
- 时间轴设计：`src/components/editor/timeline/index.tsx`
- 媒体面板：`src/components/editor/media-panel/index.tsx`
- 属性面板：`src/components/editor/properties-panel/index.tsx`

## UI2: 交互设计规则

### 核心职责
设计符合视频编辑习惯的交互模式，优化操作效率。

### 交互标准
- **拖拽操作**: 支持多选、吸附、预览等特性
- **快捷键**: 覆盖80%以上高频操作（参考 `src/hooks/use-keybindings.ts`）
- **状态反馈**: 所有操作提供即时视觉反馈
- **错误处理**: 提供清晰的错误提示和恢复方案

### 具体要求
```
交互设计规范：
1. 拖拽操作：
   - 拖拽开始：元素透明度降至50%
   - 拖拽过程：显示吸附线和目标位置预览
   - 拖拽完成：平滑动画过渡到最终位置

2. 选择操作：
   - 单选：边框高亮，显示操作手柄
   - 多选：使用选择框，支持Ctrl/Cmd+点击
   - 全选：Ctrl/Cmd+A快捷键支持

3. 时间轴操作：
   - 播放头拖拽：实时预览当前帧
   - 缩放操作：鼠标滚轮+Ctrl/Cmd组合键
   - 时间显示：精确到毫秒级别
```

### 参考实现
- 拖拽逻辑：`src/hooks/use-drag-drop.ts`
- 快捷键：`src/stores/keybindings-store.ts`
- 时间轴交互：`src/hooks/use-timeline-playhead.ts`

## UI3: 组件设计规则

### 核心职责
维护和扩展设计组件库，确保设计一致性。

### 组件规范
- **基础组件**: 基于Radix UI构建，确保可访问性
- **复合组件**: 遵循单一职责原则，便于维护
- **状态管理**: 组件状态与全局状态清晰分离
- **样式系统**: 使用Tailwind CSS变量，支持主题切换

### 具体要求
```
组件设计标准：
1. 按钮组件：
   - 主要按钮：蓝色背景，白色文字
   - 次要按钮：透明背景，蓝色边框
   - 危险按钮：红色背景，白色文字
   - 禁用状态：50%透明度

2. 输入组件：
   - 聚焦状态：蓝色边框，阴影效果
   - 错误状态：红色边框，错误图标
   - 成功状态：绿色边框，成功图标

3. 面板组件：
   - 可折叠面板：支持展开/收起动画
   - 拖拽面板：支持位置调整和大小变化
   - 浮动面板：支持拖拽移动和层级管理
```

### 参考文件
- 基础组件：`src/components/ui/button.tsx`, `src/components/ui/input.tsx`
- 复合组件：`src/components/editor/` 目录下的编辑器组件
- 样式配置：`tailwind.config.ts`

## UI4: 设计交付规则

### 交付标准
- **设计文件**: Figma源文件 + 导出的设计规范
- **切图资源**: SVG图标 + 2x/3x倍图
- **标注文档**: 详细的尺寸、间距、颜色标注
- **动效说明**: 关键交互的动画时长和缓动函数

### 具体要求
```
设计交付检查清单：
□ Figma文件结构清晰，使用组件和变量系统
□ 所有状态变化都有对应的设计稿
□ 提供暗色和亮色两套主题方案
□ 标注文档包含CSS变量名称
□ 动效说明包含具体的transition参数
□ 响应式设计覆盖1366px-1920px分辨率
```

### 协作流程
1. **需求对接**: 与产品经理确认设计需求和验收标准
2. **设计评审**: 内部设计评审 + 跨团队设计评审
3. **开发协作**: 设计走查 + 开发过程中的设计支持
4. **质量验收**: 设计还原度检查 + 用户体验验证

### 质量标准
- **设计还原度**: >95%（使用像素级对比工具验证）
- **交互流畅度**: 动画帧率 >60fps
- **可访问性**: 通过WCAG 2.1 AA标准检测
- **响应时间**: 界面响应时间 <100ms
