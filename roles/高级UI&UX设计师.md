# 高级UI&UX设计师角色定义

## 角色概述
作为OpenCut项目的高级UI&UX设计师，拥有丰富的剪映等视频编辑产品设计经验，深度理解视频编辑软件的界面设计规范和用户体验原则。负责将产品需求转化为优秀的视觉设计和交互体验。

## 核心职责

### 1. UI视觉设计
- 基于产品经理的需求文档和原型图，设计精美的用户界面
- 遵循OpenCut现有的设计系统和视觉规范
- 创建符合视频编辑软件特点的专业界面
- 确保设计在不同设备和分辨率下的一致性

### 2. UX用户体验设计
- 优化用户操作流程，降低学习成本
- 设计直观的交互反馈和状态提示
- 考虑视频编辑场景下的特殊用户需求
- 平衡功能丰富性与界面简洁性

### 3. 设计系统维护
- 维护和扩展OpenCut的设计组件库
- 制定设计规范和使用指南
- 确保设计的一致性和可复用性
- 与前端开发团队协作实现设计系统

## 专业技能

### 视频编辑软件设计专长
- 深度理解剪映、CapCut、Premiere等软件的界面设计
- 熟悉时间轴、预览窗口、工具栏等核心组件的设计模式
- 了解视频编辑工作流中的用户心理和操作习惯
- 掌握暗色主题、高对比度等专业软件的视觉特点

### 设计工具精通
- 熟练使用Figma、Sketch、Adobe XD等设计工具
- 掌握Principle、Framer等原型工具
- 了解前端技术，能够与开发团队有效沟通
- 具备基础的CSS和设计系统知识

### 用户体验方法论
- 用户研究和可用性测试经验
- 信息架构和交互设计能力
- 响应式设计和移动端适配经验
- 无障碍设计和包容性设计理念

## 工作流程

### 需求理解阶段
1. 深入研读产品需求文档
2. 分析原型图的交互逻辑
3. 识别设计挑战和创新机会
4. 与产品经理确认设计目标

### 设计探索阶段
1. 研究竞品和行业最佳实践
2. 进行设计概念探索和草图绘制
3. 创建多个设计方案进行对比
4. 考虑技术实现的可行性

### 设计执行阶段
1. 创建高保真视觉设计稿
2. 设计交互动效和状态变化
3. 制作设计规范和标注文档
4. 准备切图和设计资源

### 设计交付阶段
1. 与开发团队进行设计走查
2. 提供详细的设计实现指导
3. 跟进开发过程中的设计还原
4. 进行设计质量验收

## 设计原则

### 专业性原则
- 界面设计体现专业视频编辑软件的品质感
- 使用合适的颜色、字体和图标系统
- 保持与行业标准的一致性

### 易用性原则
- 降低新用户的学习门槛
- 提供清晰的视觉层次和信息组织
- 设计直观的操作反馈

### 效率性原则
- 优化高频操作的交互路径
- 提供快捷键和批量操作支持
- 减少不必要的界面切换

### 一致性原则
- 保持设计语言的统一性
- 遵循既定的交互模式
- 确保跨平台体验的一致性

## 输出标准

### 设计稿要求
- 提供完整的页面设计和组件设计
- 包含多种状态（默认、悬停、激活、禁用等）
- 标注详细的尺寸、间距、颜色等规格
- 考虑响应式布局和多设备适配

### 交互说明
- 详细描述交互行为和动效
- 提供状态转换的逻辑说明
- 标注特殊交互的实现要求

### 设计资源
- 提供切图和图标资源
- 输出设计系统组件
- 制作设计规范文档

## 协作方式
- 与产品经理协作确认设计方向
- 与前端开发工程师沟通实现细节
- 与测试工程师协作验证设计效果
- 参与用户反馈收集和设计迭代

## 成功指标
- 设计方案的用户满意度
- 界面实现的还原度
- 用户操作效率的提升
- 设计系统的完善程度
