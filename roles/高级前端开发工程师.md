## FE1: 功能开发规则

### 核心职责
基于设计稿和需求文档，实现高质量的视频编辑功能。

### 开发标准
- **代码规范**: 遵循 TypeScript 严格模式 + ESLint + Prettier
- **组件设计**: 基于 `src/components/ui/` 构建可复用组件
- **状态管理**: 使用 Zustand，参考 `src/stores/editor-store.ts` 模式
- **类型定义**: 完善的 TypeScript 类型，参考 `src/types/editor.ts`

### 具体要求
```
功能开发检查清单：
□ 组件支持所有必要的 props 和 ref 转发
□ 使用 forwardRef 和 memo 优化性能
□ 实现完整的键盘导航和快捷键支持
□ 所有异步操作都有loading和error状态
□ 组件支持暗色/亮色主题切换
```

### 参考实现
- 编辑器组件：`src/components/editor/timeline/index.tsx`
- 状态管理：`src/stores/editor-store.ts`
- 工具函数：`src/lib/ffmpeg/operations/basic-video-ops.ts`

## FE2: 视频处理规则

### 核心职责
实现高性能的视频处理和渲染功能。

### 技术要求
- **FFmpeg集成**: 使用 `src/lib/ffmpeg/` 中的封装函数
- **Canvas渲染**: 优化渲染性能，支持高分辨率视频
- **内存管理**: 及时释放大文件占用的内存
- **Web Workers**: 复杂计算使用 Worker 避免主线程阻塞

### 具体要求
```
视频处理性能标准：
1. 文件处理：
   - 支持 >1GB 大文件分片处理
   - 内存占用峰值 < 2GB
   - 处理进度实时反馈（每秒更新）

2. 预览渲染：
   - 1080p视频预览帧率 >30fps
   - 4K视频预览帧率 >15fps
   - 渲染延迟 < 100ms

3. 导出功能：
   - 支持多种格式和质量选项
   - 导出进度实时显示
   - 支持后台导出（Web Workers）
```

### 参考文件
- FFmpeg配置：`src/lib/ffmpeg/core/config.ts`
- 视频操作：`src/lib/ffmpeg/operations/basic-video-ops.ts`
- 导出功能：`src/lib/ffmpeg/operations/fast-export.ts`

## FE3: 性能优化规则

### 核心职责
确保应用在各种设备和网络环境下流畅运行。

### 优化标准
- **加载性能**: 首屏 < 3s，交互响应 < 100ms
- **运行性能**: CPU使用率 < 80%，内存增长 < 50MB/小时
- **网络优化**: 资源压缩率 > 70%，CDN缓存命中率 > 90%

### 具体要求
```
性能优化检查清单：
□ 使用 React.memo 和 useMemo 优化重渲染
□ 大列表使用虚拟滚动（参考媒体面板实现）
□ 图片和视频使用懒加载
□ 关键资源使用 preload 和 prefetch
□ 使用 Web Workers 处理CPU密集型任务
□ 实现增量保存和断点续传
```

### 参考实现
- 性能配置：`src/lib/ffmpeg/core/performance-config.ts`
- 存储优化：`src/lib/storage/storage-service.ts`
- 媒体面板：`src/components/editor/media-panel/index.tsx`
